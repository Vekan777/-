# Восстановленные выпуски AI Rescue Factory V1–V6

V1: файловая рабочая область и ZIP. Комплект создаётся заново из общего движка.
V2: к V1 добавлены резервное копирование, проверка SHA256 и восстановление.
V3: к V2 добавлено применение безопасных JSON-заданий ArtifactBridgeJob/1.
V4: к V3 добавлены офлайн-предложения, Ollama и HTTPS-совместимый API.
V5: к V4 добавлена очередь SQLite, защита от двойного запуска, восстановление.
V6: к V5 добавлены CI-сборки и тесты на Windows и Linux через GitHub Actions.

Важно: V1–V5 являются НОВЫМИ РЕКОНСТРУКЦИЯМИ с единым ядром,
а не байт-в-байт копиями HTML/AppBlock ZIP, которые ранее формировались
локально в приложении ChatGPT. Исторические архивы нельзя переписать
в идентичном виде без получения самих архивов.

Эти 4 бинарных файла пока НЕ ПЕРЕНЕСЕНЫ в GitHub.
V20.1/V20.2/V20.3 предоставлялись как интерактивные браузерные конструкторы.
Они не являются физически сохранёнными ZIP в библиотеке; точные исходные
бинарные пакеты для их побайтового переноса не обнаружены.
Поэтому сборка CI создаёт новые ZIP, а не выдаёт их за исторические.

# Запуск

Откройте https://github.com/Vekan777/-/actions/workflows/build-releases.yml
Дождитесь зелёной галочки. Нажмите на запуск и скачайте Artifacts.
Если оба тестовых задания Queued — архивы ещё не созданы.
Можно скачать исходники репозитория (Code -> Download ZIP) и запустить
локально: python scripts/build_releases.py --out dist

# Ограничения
Никакие ключи, пароли и закрытые данные не помещайте в публичный репозиторий.
GitHub Actions может требовать отдельного разрешения/квоты владельца.
Файловый контейнер ChatGPT не требуется для сборки через GitHub Actions.
