# AI Rescue Factory V7 Unified — отчёт о завершении базовой интеграции

Дата: 2026-10-19.

## Что объединено

- Функциональность реконструированных движков V1–V6: ZIP, контроль CRC32/SHA256, SQLite, очередь, восстановление, безопасный импорт.
- `rescue-engine/unified_v7.py`: проверка комплектов, импорт старых ZIP без изменения байтов, безопасная миграция проекта без перезаписи.
- `rescue-engine/ai_pipeline.py`: режимы offline / Ollama / HTTPS-compatible API; ИИ-код не запускается автоматически.
- `gui_v7.py`: Windows Tkinter UI с проверками, резервными копиями, восстановлением и доступом к Anime Factory.
- Оригинал Anime Factory V19 HTML (239 911 байт UTF-8), сохранён отдельно и в backup.
- Восстановленный патч V20.3 Preservation Candidate, основанный на V19. Сложная история версий аниме выше V19 не реконструирована побайтово.
- Шесть вложенных архивов V1–V6 и тесты.

## Результаты реального тестирования

- GitHub Actions: https://github.com/Vekan777/-/actions/runs/39286748398 — `completed/success`.
- Тестирование выполнено на Windows и Linux в удалённых runner-окружениях (Python 3.13).
- 14 регрессионных тестов прошли, включая обнаружение повреждённого ZIP, пути с `../`, защиту от перезаписи, без потерь при переносе, повторный импорт.
- `engine.py selftest` — PASS; `unified_v7.py selftest` — PASS.
- ZIP, созданный Python в CI: 28 полезных файлов, 639 223 байта, V7 манифест и SHA256 проверены.
- GitHub Actions выложил полный набор ZIP-архивов как артефакт: https://github.com/Vekan777/-/actions/runs/39286748398/artifacts/12203850830.
- Дополнительно аварийный JS-сборщик создал отдельный V7 ZIP на 992 617 байт и проверил его CRC32, плюс включил SHA256-манифест. Этот ZIP опубликован в `downloads/` и не побайтово совпадает с архивом CI.

## Что остаётся не подтверждено

- Запуск GUI на пользовательском ноутбуке с Windows 10 и видеокартой GT 740M; удалённые проверки не включают ручное тестирование интерфейса.
- Рендеринг аниме и художественное качество; V19/V20.3 остаются 2D-аниматиком/редактором, не 3D-топ-аниме.
- Архивы V19 EXAMPLE_EPISODE ZIP, исходный V19 IMPACT WINDOWS ZIP, MP4 и PNG из ChatGPT Library в GitHub не копировались.
- Поведение платных внешних API и Ollama модели в пользовательской среде.

## Запуск Windows 10

1. Скачайте `downloads/AI_RESCUE_FACTORY_V7_UNIFIED_CANDIDATE_WINDOWS.zip`.
2. Распакуйте в новую папку на NTFS, не запускайте BAT из ZIP.
3. Установите Python 3.10+ x64 (если нет).
4. Дважды нажмите `TEST_V7_WINDOWS.bat` — две строки `SELFTEST PASS`.
5. Откройте `RUN_V7_WINDOWS.bat` — графическая оболочка Tkinter.
6. Папка `legacy/` содержит V1–V6, `anime-factory/` V19 и V20.3.

Выпуск CI-verified по программным тестам. Итоговую пользовательскую аттестацию рекомендуется выполнить на ноутбуке перед продуктивной работой.
