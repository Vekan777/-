# AI Rescue Factory

Репозиторий проекта автономной системы разработки и сборки файлов.

## Статус

Подключение ChatGPT к GitHub проверяется. Код AI Rescue Factory V5 и автоматические тесты будут добавляться отдельно после проверки и сборки.

## Правила

- Не сохранять пароли, API-ключи и токены в репозитории.
- Перед публикацией проверять ZIP, SHA-256 и восстановление.
- Хранить исходники по версиям и не выдавать непроверенные выпуски за финальные.

Этот README — безопасная стартовая страница проекта, а не готовый дистрибутив V5.
