# AI Anime Factory V50.1 — CINEMATIC 2D / РУССКИЕ ПИЛОТЫ

## Зачем V50.1

Пользователь посмотрел V50 и сообщил, что лица всех актёров слишком
похожи, бой неубедителен, а голос должен быть на русском языке.
Это **исправительная версия** поверх V50, не новая фабрика, не V51 и не 3D.
Базовая V50 не переписывается. Исторический V19–V50 сохранён.
Изменён только пилотный визуальный конвейер V50.1.

## Что реально изменено

1. Новый **пилотный** Canvas-рендер: Акира, Мию, Рэн, Сайра,
   Архонт и безликий страж имеют индивидуальную геометрию, глаза,
   волосы, костюмы, рост, детали и оружие.
2. Шесть характерных сценических окружений: развалины города,
   мост, боевые колонны, память/дневник, тайная сделка, врата.
   Разные планы и драматический свет, а не один фон для всей серии.
3. Бой поставлен по последовательным фазам: дистанция, сближение,
   отражение удара, контрвыпад, раскрытие щита, призыв, контакт,
   отбрасывание и последствие. Анимированная траектория клинка,
   вспышка попадания, изменение опоры и состояния героя.
   Это **процедурная 2D-анимация**; отсутствие дефектов требуется
   проверить по реальным кадрам и всему видео.
4. Русские реплики обоих актёров сцены озвучиваются через eSpeak NG
   в режиме локального черновика. Исходные 24 реплики, две разные
   роли в каждой сцене, временные отметки и WAV/MP3 сохраняются
   в полном переносимом JSON. При движении рта V50.1 ориентируется
   на **текущий** временной отрезок говорящего, не всегда на героя.
5. В браузере в разделе «ФИНАЛЬНАЯ QA V50» можно переключить
   новую графику и старый рендер. Для пилотов 01–02 новая графика
   включена в сохранённом JSON. Старые и другие проекты продолжают
   использовать исходный V50.
6. Предусмотрены реальный Playwright/Chromium рендер, WebM, MP4
   H.264/AAC, проверка слышимого звука, перезапуск очереди,
   12 кадров сцен, девять ключевых боевых кадров, SHA256.
7. Все оригинальные сюжетные описания V19/V20 дополнительно
   хранятся в \`pilotV50.sourceSceneTextV19\` и
   \`pilotV50.originalStoryV20\`, исходный V50 проект не изменён.
   Работа с первой парой серий не затрагивает остальные эпизоды.

## Что пока НЕ соответствует уровню большой аниме-студии

Встроенная новая иллюстрация детальнее старой, но она по-прежнему
нарисована программой Canvas, а не профессиональными художниками
и не моделью генерации студийных покадровых анимаций. Слова «огонь»
сами по себе не превращают процедурный рисунок в шедевр.
Текущая eSpeak NG выдаёт понятную **русскую роботизированную речь**,
а не артистически достоверные голоса с дыханием, эмоциями и игрой.
V47 по-прежнему использует амплитуду и тайминги звука, не фонемное
моделирование. В каждом видеоролике нет доказанной коммерческой лицензии
на сторонние материалы или формального художественного одобрения.

Для настоящего коммерческого сериала следующими действиями будут
замена временной речи актёрской/качественной лицензированной русской
нейроозвучкой, импорт многослойных авторских персонажей и локаций,
ручная постановка и художественная экспертиза каждой сцены. Нельзя
объявлять V50.1 профессиональным сериалом только потому, что CI зелёный.

## Сколько версий

V49 — уже существующая объединяющая. V50 — исходная техническая база.
**V50.1** — это исправление визуала/действий и русской речи.
**V50.2 UNIFIED ACCEPTANCE** — последний намеченный этап: согласованный
канон всего сезона, финальные голоса/арт, реальные эпизоды, права,
проверка Windows 10 и ZIP «под ключ». 3D Edition — только после
художественного приёма 2D. Не создавать бесконечные V51/V52.

## Запуск на Windows 10

1. Скачайте файл \`AI_ANIME_FACTORY_V50_1_CINEMATIC_WINDOWS.zip\` из
   GitHub Actions **успешного** V50.1 CI (по ссылке в PR/README).
2. Полностью распакуйте в **новую отдельную** папку.
3. Запустите \`RUN_WINDOWS.bat\` — откроется полный редактор V50+V50.1
   в Chrome/Edge. При необходимости откройте HTML вручную.
4. Импортируйте \`PROJECT_PILOT_V501.json\` через восстановление JSON.
   Сохраните его копию в безопасное место.
5. Откройте «ФИНАЛЬНАЯ QA V50», включите «Кинографика V50.1», затем
   «Монтаж серий V48». Посмотрите оба эпизода и сравните работу боя.
6. Для MP4 переименуйте/сохраните проект как \`PROJECT_INPUT.json\`
   рядом с пакетными BAT. Потребуются Python 3.11+, Playwright Chromium
   и FFmpeg. Один раз запустите \`SETUP_BATCH_WINDOWS.bat\`,
   затем \`RUN_BATCH_WINDOWS.bat\`.
7. Файл \`ffmpeg-9.0.2-full_build.zip\` у пользователя уже есть:
   после распаковки положите \`ffmpeg.exe\` и \`ffprobe.exe\` в
   \`tools\ffmpeg\bin\`. **Не нужно скачивать его повторно.**
8. MP4/WebM/SRT/VTT будут в \`OUTPUT\`. Пакетную запись можно
   повторить, уже готовые эпизоды проверяются по SHA256.

Для ноутбука Intel i7-3630QM / 8 GB / GT740M запускайте 640×360 6 FPS.
Не обещается плавная 1080p/24 FPS на этом железе. Храните резервные
JSON и оригинальную опубликованную V50 отдельно.

## Что проверять перед публикацией

- Узнаваемость героев по силуэту даже без цвета, читаемость позы.
- Наличие 9 *разных* боевых состояний в течение эпизода.
- Соответствие движения рта второму говорящему, включая тишину.
- Понятность русских реплик, обрывы голосов, тишина между фразами.
- Причинность: цена призыва душ, раны, память, предательство,
  доверие и постепенное развитие любви без переписывания канона.
- Контраст и безопасность субтитров в 640×360 на телефоне.
- Реальные MP4 **целиком** и повторный экспорт на Windows 10.
- Документы прав и письменное утверждение художественного результата.
