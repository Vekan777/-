# AI Anime Factory V44 — True Actor Keyposes

V44 добавляет **настоящие движения в существующий процедурный 2D-риг персонажа**, а не новую накладку на кадр. Модификации выполняются внутри оригинальных вызываемых при рисовании `v24Dynamics` и `v24FootPose` поверх настроек V39. История и исходы боёв определяются только V19/V25.

## Новые возможности

- **Боевая стойка и перенос веса** даже между моментами удара.
- **Дополнительный размах руки, поднятие блока, подготовка и отведение корпуса** в соответствии с каноническими временными событиями.
- **Более устойчивые ступни, опорные и подвижные шаги, уход в сторону при уже существующем dodge**.
- **Реакция на подтверждённое hit**, инерция движения и вторичная анимация волос и ткани. Не создаются фиктивные попадания или смерти.
- Три стилистических пресета: «Устойчивая стойка», «Быстрый и подвижный», «Тяжёлый удар»; шесть ползунков силы по сценам.
- Настройки хранятся исключительно в `scene.keyposesV44`. V19–V43 полностью сохранены, включая V35 таймлайн, V36 аудио/WebM, V37 субтитры, V38–V43 оформление камеры.
- Реальный предпросмотр серии, сравнение двух пар кадров **до/после в одном таймкоде**, PNG-контроль, JSON-план и эвристический аудит.

## Полная инструкция запуска Windows 10 64-бит

1. Скачайте `AI_ANIME_FACTORY_V44_TRUE_KEYPOSES_WINDOWS.zip` по прямой ссылке GitHub или из Releases, распакуйте его **полностью в отдельную новую папку**. Не заменяйте прежние V35–V43.
2. Запустите `RUN_WINDOWS.bat` двойным щелчком либо откройте `AI_Anime_Factory_V44_TRUE_KEYPOSES.html` в Chrome/Edge. Для редактора Python не нужен.
3. Перед изменениями экспортируйте резервный **полный JSON проекта** на вкладке «Аудит V30». При работе в том же браузере V44 пробует загрузить предыдущий локальный V43; при переносе файлов импортируйте резервный JSON вручную.
4. На вкладке **«Позы персонажей V44»** выберите серию и именно боевую сцену. Новые движения в диалогах сознательно не применяются.
5. Настройте профиль, стойку, размах рук, защиту, инерцию, работу ног и движение ткани. Сохраните сцену.
6. Запустите предпросмотр, сравните кадры с выключенным/включённым V44. Кнопка PNG создаёт четыре кадра, где каждая пара содержит оригинал и вариант V44 **для одного и того же времени**.
7. Скачайте JSON настроек V44 и проверьте замечания аудита: предупреждения о чрезмерной амплитуде помогают заметить неестественные движения, но не являются художественной экспертизой.
8. Для создания настоящего WebM со звуком перейдите в прежнюю вкладку **«Звук / экспорт V36»**, заново подключите собственные WAV/MP3/OGG, если браузер перезапускался. Нажмите «Записать V44 с позами персонажей». Видеозапись идёт в реальном времени.
9. Для MP4 перенесите WebM на `CONVERT_MP4_WINDOWS.bat`. Требуется локальный `ffmpeg.exe` в `tools/ffmpeg/bin/` или в системном PATH. Вы можете использовать имеющийся FFmpeg 9.0.2 после распаковки.
10. По окончании сохраните **весь проект JSON**, новые PNG и исходные аудиофайлы отдельно. Бинарные звуки не встроены в JSON.

## Проверка и границы

Windows/Linux, Node.js, Chromium: подтверждаются реальные изменения пикселей процедурного персонажа при включении V44, движение на разных кадрах, неразрушение старого сценария/персонажей/исходов боя, аудио- и видеодорожки WebM с проверкой FFprobe, контроль CRC32/SHA256. Старый V19 и полный V43 ZIP доступны в резерве архива. Выпускается и объединённый V7 со всеми предыдущими версиями.

```bash
python anime-factory/v44/build_keyposes_v44.py --selftest
python -m unittest discover -s tests -p "test_anime_v44.py" -v
python scripts/build_anime_v44.py --selftest
python anime-factory/v44/build_keyposes_v44.py --output dist/AI_Anime_Factory_V44_TRUE_KEYPOSES.html
python tests/smoke_browser_v44.py --html dist/AI_Anime_Factory_V44_TRUE_KEYPOSES.html --out dist/V44_TRUE_RIG_SAMPLES
```

V44 остаётся **процедурной 2D-анимацией**. Она не создаёт 3D-модели и не автоматически превращает импортированные PNG в скелетированный риг. Для вашего ноутбука Windows 10 с 8 ГБ RAM и GeForce GT740M начните с 640×360 при 6 FPS и коротких сцен.
