# AI Anime Factory V37 — Subtitle & Episode Delivery Quality

V37 — отдельная надстройка над настоящими V19–V36. Не переписывает предыдущие исходники, длительности сцен, канон, 3D-обещания или пользовательскую озвучку. История проекта и исходный V19 сохраняются.

## Что добавлено
- Редактор субтитров на каждый эпизод и сцену: начало, конец, персонаж, реплика. Отдельное поле `subtitlesV37`; сюжетные данные и переходы V35 не переписываются.
- Экспорт настоящих файлов **SRT и WebVTT** с началом и окончанием реплик на **общем таймкоде V35**, даже когда соседние сцены накладываются.
- Предпросмотр с реальным наложением реплик поверх Canvas, включая переходы V35.
- Запись видео из вкладки «Звук / экспорт V36» **включает субтитры V37 прямо в пиксели записанного WebM**, без замены аудиодвижка V36. MP4 по-прежнему получается через локальный FFmpeg и прилагаемый BAT.
- Аудит пустых реплик, неверной длительности, слишком высокой скорости чтения и перекрывающихся субтитров. CSV/автоматического перевода или генерации озвучки пока нет.
- ZIP: подлинный V19, все прежние исходники и рабочий архив V36 в `backup/`, инструкцию, манифест SHA256/CRC32.

## Запуск Windows 10 x64
1. Скачайте ZIP V37 и **полностью распакуйте в новую папку**, не поверх V35/V36.
2. Откройте `RUN_WINDOWS.bat` или `AI_Anime_Factory_V37_SUBTITLES_DELIVERY.html` в Chrome/Edge. Python для открытия HTML не требуется.
3. Перед изменениями откройте «Аудит V30» и скачайте полный JSON проекта. V37 подхватывает сохранённый V36, но экспортированный JSON надёжнее при смене компьютера или браузера.
4. Откройте «Субтитры V37», выберите эпизод, сцену, «Новые субтитры». Укажите начало и конец **относительно сцены**, говорящего и текст.
5. Нажмите «Сохранить реплику»; повторите. Проверьте предпросмотр и «Проверить все субтитры».
6. Скачайте **SRT**, **WebVTT** и **JSON-план**, затем сохраните резервный полный JSON проекта в «Аудит V30».
7. Для реального ролика со звуком откройте «Звук / экспорт V36», при необходимости снова прикрепите WAV/MP3/OGG для речи, музыки, эффектов и нажмите «Записать WebM с субтитрами V37».
8. Дождитесь окончания **реального воспроизведения**. Браузер скачает `V37_EPISODE_SUBTITLES_....webm`. При отсутствии аудиофайлов слышимого звука не будет.
9. Для MP4 поместите WebM рядом с `CONVERT_MP4_WINDOWS.bat` и запустите BAT. Для этого установите FFmpeg в PATH или поместите `ffmpeg.exe` по пути `tools/ffmpeg/bin/ffmpeg.exe`. Можно использовать ранее скачанный архив `ffmpeg-9.0.2-full_build.zip` после распаковки.
10. Исходные WAV/MP3/OGG остаются в памяти браузера, а не внутри JSON — **их необходимо повторно выбрать** после перезапуска редактора.

На ноутбуке с 8 GB RAM и GT740M начните с 640×360 и 6 FPS. V37 — процедурный **2D-аниматик** с реальным WebM, а не профессиональная 3D-анимация. Сюжетная художественная согласованность требует авторской проверки; автоматические тесты подтверждают техническую сохранность отдельных данных.

## Проверки
- `python anime-factory/v37/build_subtitles_v37.py --selftest`
- `python -m unittest discover -s tests -p "test_anime_v37.py" -v`
- `python scripts/build_anime_v37.py --selftest`
- `python anime-factory/v37/build_subtitles_v37.py --output dist/AI_Anime_Factory_V37_SUBTITLES_DELIVERY.html`
- `python tests/smoke_browser_v37.py --html dist/AI_Anime_Factory_V37_SUBTITLES_DELIVERY.html --out dist/V37_SUBTITLE_SAMPLES`
- `python scripts/build_v7.py --legacy dist --out dist` (после создания прежних ZIP, как в основном CI V7).

Тесты Windows/Linux, Node.js, Chromium, реальные Canvas PNG, SRT/VTT и аудио/видео WebM выполняются в GitHub Actions. Сохранены старые тесты основной сборки V19–V35, V36 и новый набор V37.
