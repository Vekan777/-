# AI Anime Factory V48 — Episode Production Engine

Это **четвёртая из шести фиксированных 2D-версий V45–V50**. V48 добавляет не ещё один эффект, а реальное производство видео отдельных эпизодов и целого сезона с проверяемыми файлами.

## Что реализовано

- Выбор настоящей серии и полный просмотр сцен по V35-таймлайну с героями/2D-слоями V45, движениями V46, камерой, фонами и звуком V47.
- Финальная карточка титров рисуется в последних секундах серии без удаления сюжетных сцен и изменения времени истории. Это минимальные титры, **не** полный профессиональный список участников.
- Экспорт **SRT и VTT** из действующих V37 субтитров, режиссёрский shot list, полный паспорт сезона и портативный JSON с картинками/аудио. Экспорт PNG четырёх контрольных кадров.
- Запись одного WebM с видеорядом и Web Audio через проверенный V36 MediaRecorder.
- **Новый `scripts/render_anime_v48.py`** — пакетный рендер нескольких серий с Playwright/Chromium, 6/12/24 FPS, сохранением очереди на диске, реальными аудио/видео-дорожками, верификацией FFprobe, конвертацией H.264/AAC MP4 через локальный FFmpeg. Проверенные SRT/VTT рядом с видео.
- **Восстановление рендера по эпизодам:** `V48_RENDER_CHECKPOINT.json` включает SHA256 исходного проекта, HTML, настройки FPS и контрольную сумму каждого готового WebM. При перезапуске пропускает только серии, у которых проверены файлы, дорожки и контрольные суммы. Серия, прерванная на середине, **начинается заново**.
- Всё выполнено последовательно: одновременно не держит тысячи PNG или несколько видео в памяти Python. Обратите внимание, что браузерные WebM записываются **в реальном времени**, а не в сотни раз быстрее видео.

## Обычный запуск Windows 10 x64

1. Скачайте `AI_ANIME_FACTORY_V48_EPISODE_ENGINE_WINDOWS.zip` из GitHub Releases, полностью распакуйте в **новую папку**. Не заменяйте предыдущий V47.
2. Запустите `RUN_WINDOWS.bat`. Основной HTML откроется в Chrome или Edge, Python для самого браузерного редактора не нужен.
3. Если были собственные проекты в V47, откройте V48 в том же браузере или вручную импортируйте сохранённый JSON. Создайте отдельную резервную копию данных перед дальнейшим монтажом.
4. Перейдите на **«Монтаж серий V48»**. Выберите серию и проверьте полный предпросмотр, начало/конец сцен, титры и аудио. Откройте V37, чтобы редактировать субтитры.
5. Сохраните параметры (6/12/24 FPS, название студии, титры). Скачайте SRT, VTT, режиссёрский JSON, паспорт сезона и **полный портативный JSON** с рисунками и звуком.
6. Для одной серии нажмите «Записать выбранную серию WebM». В браузере разрешите скачивание файла. Для больших файлов учтите свободное место на диске.
7. Чтобы выпустить **весь сезон, WebM+MP4**, используйте инструкции ниже. Для слабого ноутбука начните с 640×360, 6 FPS и одного короткого тестового эпизода.

## Автоматическая пакетная обработка под ключ на Windows

1. Установите **Python 3.11 или новее** для Windows x64 с официального сайта <https://www.python.org/downloads/windows/>. При установке отметьте добавление Python в PATH. Достаточно один раз.
2. FFmpeg для MP4: используйте уже имеющийся `ffmpeg-9.0.2-full_build.zip`. После распаковки разместите `ffmpeg.exe` и `ffprobe.exe` в `tools\ffmpeg\bin\`, либо добавьте эту папку в PATH.
3. Запустите `SETUP_BATCH_WINDOWS.bat` один раз с подключением к интернету. Скрипт устанавливает Python Playwright 1.56.0 и официальный браузер Chromium для автоматического видеорендера. Установка занимает диск и **ничего не удаляет**.
4. Из работающей V48 нажмите «Полный проект с артом и звуком» и сохраните файл **`PROJECT_INPUT.json` рядом с `RUN_BATCH_WINDOWS.bat`**. Это обязательно, чтобы перенести и сценарий, и ваши PNG/WAV.
5. Двойным щелчком запустите **`RUN_BATCH_WINDOWS.bat`**. Скрипт последовательно обрабатывает все серии, записывает `OUTPUT\episode_01.webm`, `.mp4`, `.srt`, `.vtt` и файлы `V48_RENDER_CHECKPOINT.json`, `V48_SEASON_RENDER_MANIFEST.json`. Для слабого ПК рекомендуются настройки 6 FPS.
6. При сбое запускайте тот же BAT ещё раз. Если файл серии цел, совпадают SHA256 проекта/сборки/FPS и FFprobe проверяет обе дорожки, он **не перерисовывается**. Неполная серия будет полностью записана заново.
7. Не меняйте JSON или HTML в процессе рендера. Любое изменение файла автоматически отменяет повторное использование ранее проверенной очереди.
8. Отдельные видео и субтитры можно загружать на законно доступные видеоплатформы после художественного просмотра, лицензирования аудио/арта и исправления замечаний.

Командная строка для опытных пользователей:

```bat
python source\V48_render_anime_v48.py --html AI_Anime_Factory_V48_EPISODE_ENGINE.html --project PROJECT_INPUT.json --out OUTPUT --episodes 1,2 --fps 6 --mp4
```

## Контроль качества и ограничения

- Проверяются реальные видео+аудио потоки (FFprobe), длительности, SHA256, SRT/VTT, отсутствие ошибок браузера, две различные серии, валидность MP4 H.264/AAC и повторный запуск без перерендера готовых серий.
- Если в проекте нет загруженных звуков, WebM может иметь технически существующую, но **немую** дорожку. Для готового сериала требуются действительно записанные и лицензированные голоса/музыка.
- Полная серия записывается **в реальном времени**, включая каждый эпизод последовательно. Пакетная работа требует установленного Python, Chromium и FFmpeg; браузерный одиночный экспорт запускается без них.
- Встроенный WebM работает с Canvas 640×360. Другие размеры отмечены как параметры будущего рендера, но **не считаются уже проверенным экспортом 1080p**.
- Контроль восстановления работает **с границы готового эпизода**. Нет восстановления с произвольного отдельного кадра в середине WebM.
- V47 пока ограничивает переносимый звуковой клип до 1,5 МБ (ограничения браузерного localStorage). Большие многоминутные серии с сотнями аудиоклипов могут потребовать внешней проектной файловой базы и оптимизации.
- V48 **не объявляется окончательной профессиональной студией**. Нет полного фантомно «автоматического» производства художественного сериала; качество моделей, драматургии, монтажа, актёрских эмоций и сведения звука проверяется вручную.
- Далее строго **V49 UNIFIED**, **V50 FINAL / DEEP QA**, затем отдельная 3D Edition после приёмки V50.
