# AI Anime Factory V41 — Character Silhouettes & Costume Studio

V41 добавляет **три новых различимых силуэта персонажей** в реальный процедурный 2D-риг: **Защитник** (широкие плечи и доспех), **Разведчик** (асимметричная форма, волосы с хвостом) и **Маг** (длинная мантия, высокий воротник, эмблема). Новые элементы участвуют в движении вместе с корпусом, головой и ногами. Это не слой поверх целого экрана.

Проект построен **поверх V40**. Исходные файлы V19–V40, авторские сцены, сюжет, события боя, длительности, монтаж V35, звук и реальный WebM V36, субтитры V37, цвет V38 и анимация V39 сохраняются. Параметры новых силуэтов хранятся исключительно в `character.silhouetteV41`.

## Реализовано

- Плащ и длинная мантия с детерминированным движением ткани по времени кадра — привязка к V23/V24/V39, без симуляции, требующей мощного ПК.
- Новая линия плеч и брони, высокий воротник, цветной герб, контуры сапог и выразительные боковые/верхние пряди волос.
- Настраиваемые силуэты, палитра, плащ, плечи, воротник, сапоги, волосы и герб — отдельно для каждого персонажа.
- Настоящие два Canvas кадра **до и после при одинаковом времени**; контрольный лист PNG 2×2 и JSON настроек.
- Архив содержит оригинальный V19, исходники предыдущих версий и полный архив V40; проверяются SHA256 и CRC32.

## Полная инструкция Windows 10, 64-бит

1. Скачайте `AI_ANIME_FACTORY_V41_SILHOUETTE_STUDIO_WINDOWS.zip` по ссылке в GitHub Releases или через папку `downloads/`. Распакуйте полностью **в новую папку**. Папки V35–V40 не стирайте.
2. Откройте `RUN_WINDOWS.bat` двойным щелчком. Альтернатива — открыть `AI_Anime_Factory_V41_SILHOUETTE_STUDIO.html` в Chrome/Edge. Python не требуется для открытия редактора.
3. Сначала на вкладке «Аудит V30» экспортируйте полный резерв проекта JSON. При работе в том же браузере V41 может импортировать прежний локальный V40; при смене браузера используйте экспортированный JSON.
4. Перейдите в «**Силуэты V41**». Выберите персонажа, тип (Защитник/Разведчик/Маг), палитру и настройки частей. Сохраните.
5. Сравните реальный Canvas **до/после** в том же таймкоде. При необходимости найдите сцену, где выбранный персонаж участвует; иначе изображение не обязано измениться.
6. Скачайте 4 кадра PNG, JSON-план и отчёт аудита читаемости, проверьте силуэт в эпизоде в редакторах V35–V40.
7. Для видео откройте прежний «Звук / экспорт V36». Загрузите свои WAV/MP3/OGG заново, если перезапускали программу. Нажмите «Записать V41 с силуэтами и костюмами». По окончании **реального воспроизведения** браузер скачает WebM.
8. Для MP4 используйте `CONVERT_MP4_WINDOWS.bat` и локальный FFmpeg. Поместите `ffmpeg.exe` в `tools/ffmpeg/bin/ffmpeg.exe` либо установите FFmpeg в PATH. Подходит и ваш ранее скачанный `ffmpeg-9.0.2-full_build.zip` после распаковки.
9. Сохраните итоговый полный JSON проекта и отдельно резерв своих звуковых файлов. Бинарные аудиофайлы не хранятся в JSON.

### Производительность

Для ноутбука Windows 10, 8 ГБ ОЗУ, GeForce GT740M и Intel HD Graphics 4000 начните с **640×360, 6 FPS**. Новой тяжёлой нейросети или мощного графического рендера в V41 нет.

**Ограничение:** V41 улучшает встроенную **2D-векторную** модель и не создаёт автоматически новые профессиональные 3D-модели, художественные анимационные листы или анимацию импортированных PNG/PSD. Структурные и пиксельные тесты проверяют техническую работу, но качество рисунка следует оценивать вручную.

## Проверки

```bash
python anime-factory/v41/build_silhouette_v41.py --selftest
python -m unittest discover -s tests -p "test_anime_v41.py" -v
python scripts/build_anime_v41.py --selftest
python anime-factory/v41/build_silhouette_v41.py --output dist/AI_Anime_Factory_V41_SILHOUETTE_STUDIO.html
python tests/smoke_browser_v41.py --html dist/AI_Anime_Factory_V41_SILHOUETTE_STUDIO.html --out dist/V41_SILHOUETTE_SAMPLES
```

В GitHub Actions запускаются Windows, Linux, Node.js, браузер Chromium, подтверждённые до/после PNG, SRT/VTT/звук из старого редактора, WebM с видео+аудио и объединённая фабрика V7 со всеми прошлыми версиями. Для каждого архива действует инвентаризация и хеширование SHA256.
