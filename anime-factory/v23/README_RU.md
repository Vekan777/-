# AI Anime Factory V23 — Character Quality

**Статус:** исходники V23, проверка в CI требуется до обозначения выпуска как «проверенного».

## Что улучшено
- У каждого персонажа настраивается профиль телосложения: сбалансированный, героический, стройный. Пропорции головы и силуэта меняются согласованно.
- Дополнительная форма корпуса, суставы рук, наколенники, контуры голени и ладоней — именно процедурный 2D-риг.
- Более читаемые пряди волос, материалы, швы и блики одежды.
- Детерминированное вторичное движение волос, ткани и тела; одинаковое время кадра даёт одинаковую позу.
- Редактирование персонажей через новую вкладку **«Персонажи V23»**, экспорт TXT-паспорта и контактного листа из четырёх PNG.
- Проекты сохраняют поля `qualityV23` для каждого персонажа в JSON. При загрузке используется также существующий ключ V22, не удаляя данные прежних версий.
- Встроенные сцены, история, канон, память, сюжет V20, освещение V21, актёрские ключи V22 остаются в объединённом HTML.
- Загруженные авторские PNG и послойные иллюстрации не перерисовываются; эффект V23 применяется к процедурному fallback-ригу.

## Запуск для Windows 10
1. Скачайте ZIP после завершения проверок GitHub Actions, распакуйте полностью.
2. Запустите `RUN_WINDOWS.bat` или откройте `AI_Anime_Factory_V23_CHARACTER_QUALITY.html` в Chrome либо Edge.
3. Выберите вкладку «Персонажи V23», персонажа, профиль и параметры.
4. Нажмите «Сохранить персонажа V23», затем экспортируйте JSON проекта как резервную копию.
5. Сохраните четыре PNG кадра, чтобы сравнить внешность и пластику.
6. Для 8 ГБ RAM используйте 640×360, 6 FPS; для MP4 потребуется внешний FFmpeg.

**Важно:** работающий HTML — процедурный 2D-аниматик, не полноценная 3D-анимация и не нейросетевой видеогенератор. Художественное качество потребует собственных изображений и ручной работы.

## Разработчикам
- `anime-factory/v23/character_v23.js` — детализирующие функции и интерфейс.
- `anime-factory/v23/build_character_v23.py` — последовательная сборка V19→V20→V21→V22→V23.
- `tests/test_anime_v23.py` — регрессии, детерминизм и `node --check`.
- `tests/smoke_browser_v23.py` — реальный Chromium: кадры до/после, сохранение V20–V23 через перезагрузку, экспорт PNG.
- `scripts/build_anime_v23.py` — ZIP, SHA256-манифест и CRC32.
- `scripts/build_v7.py` — объединение V23 с V7 и более ранними выпусками.

Команды: `python anime-factory/v23/build_character_v23.py --selftest`, `python -m unittest discover -s tests -p "test_*.py" -v`, `python scripts/build_anime_v23.py`.

Контрольные изображения и ZIP после CI доступны на странице [GitHub Actions](https://github.com/Vekan777/-/actions/workflows/build-releases.yml).
