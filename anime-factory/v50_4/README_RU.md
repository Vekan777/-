# AI Anime Factory V50.4 — русские голоса пяти персонажей

**Состояние: технический 2D-пилот. НЕ завершённое профессиональное аниме.**

В V50.4 выполнен отдельный проход озвучки персонажей. Используется
одна модель Silero **v5_cis_base** с лицензией MIT, которая назначает
разные голоса пяти персонажам (для технических демо, а не имитации
живых актёров):

- Акира — \`ru_roman\`
- Мию — \`ru_ekaterina\` (женский)
- Рэн — \`ru_dmitriy\`
- Сайра — \`ru_karina\` (другой женский)
- Архонт — \`ru_eduard\` (уникальный антагонист)

Модели Denis и Dmitri из V50.3 остаются сохранёнными в предыдущем
архиве: они не удаляются. V50.4 использует пять разных голосов Silero,
чтобы воспроизвести полный сезон без недостающих женских ролей.
Нейросинтез не заменяет профессиональную актёрскую игру.

## Что делают тесты

GitHub Action \`anime-v504-neural-two-episodes.yml\` изготавливает
новую озвучку для всех 72 реплик в 36 сценах/6 коротких пилотах
и **только первые 2** пересобирает в H.264/AAC MP4 960×540/12 FPS.
Источник — JSON и Canvas, а НЕ прежний MP4. Реплики, имена,
потери памяти и сюжет сохраняются; новый звуковой проект отдельно
от оригинала. Голосовой буфер не обрезается: если реплики длиннее,
длительность сцены расширяется, субтитры пересчитываются по длине WAV.
Музыкальная дорожка и эффекты остаются из V50.2.

Отдельные контрольные состояния по-прежнему \`false\`: художественная
приёмка, коммерческие права всего сериала, утверждённая актёрская
игра и точный фонемный lip-sync. Движение рта в текущем движке
управляется амплитудой (50 Гц): это НЕ точная артикуляция.
Иллюстрации персонажей нельзя считать многослойной полноценной
рисованной анимацией. Удары всё ещё не прошли профессиональную
проверку анатомии, физики, ритма, веса и монтажа.

## Как запустить на Windows 10

1. Распаковать успешно собранный ZIP в отдельную папку.
2. Открыть \`RUN_WINDOWS.bat\`; новые пять голосов уже находятся
   ВНУТРИ сохранённого проекта, дополнительные TTS не требуются
   для воспроизведения.
3. Проект \`PROJECT_FIVE_NEURAL_RUSSIAN.json\` — резервная копия,
   которую можно импортировать при необходимости. НЕ загружайте
   его в старую V50, для которой не предназначен этот формат.
4. Папка \`VIDEOS\` содержит две новые видео-серии и SRT;
   \`FRAME_SAMPLES\` — реальные кадры редактора.
5. Для повторного локального рендера нужны Python, FFmpeg и
   Playwright Chromium. На старом i7-3630QM / GT740M 2GB
   используйте 640×360, 6 FPS, а не 12 FPS.
6. Для самостоятельного НОВОГО синтеза модель Silero требует
   современного CPU с AVX2 и PyTorch. Ваш i7-3630QM AVX2 не
   поддерживает: озвучку на этом компьютере НЕ пытайтесь
   самостоятельно генерировать через Silero. Готовые WAV/MP3
   внутри JSON можно проигрывать без AVX2.

## Что осталось перед реальным художественным завершением

- Отдельные оригинальные многослойные нарисованные персонажи
  для всех ракурсов, с лице- и тело-ригами;
- точное выравнивание русских фонем с реальной речью
  и приёмка мимики/выражений;
- хореография боёв с физическим контактом, последствиями,
  одинаковыми костюмами/лицами в последовательных кадрах;
- режиссёрская, звуковая и сюжетная ручная приёмка,
  права на все медиа, коммерческие условия;
- настоящие длинные эпизоды (нынешние — примерно минутные пилоты).
