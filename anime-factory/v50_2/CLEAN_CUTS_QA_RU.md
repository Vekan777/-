# AI Anime Factory V50.2 — MOTION RIG / CLEAN CUTS исправление

Развитие прежней V50.2, без создания V50.3/V51. Сюжетный оригинал V19–V50 и 6 эпизодов сохранены.

**Реальная проблема:** ранний ART PASS делал наложение прозрачного аниме-портрета на фигурную векторную анимацию, из-за чего в бою появлялись «двойные» персонажи.

**Исправление:** файл `clean_cuts_v502.js` вводит отдельные непрозрачные иллюстрированные планы. Большие портреты больше не смешиваются с MOTION RIG, но суставная векторная анимация остаётся в общих боевых планах. Режим можно отключить. Движение камеры над иллюстрацией — Ken Burns, не покадровая анимация лица или тела.

**Действительная локальная проверка 21.10.2026:** Chromium загрузил все 13 JPEG и без ошибок отрисовал 12 сюжетных кадров; переключатель отключает и включает CLEAN CUTS, сравнение изображений показывает реальное изменение кадра без изменения исходного канона. Оба эпизода **перерендерены** в 640×360, 6 FPS, по 423 кадра, 70,5 сек, H.264/AAC с временной русской TTS-аудиодорожкой. Слышимый звук: максимумы -3.1/-3.0 dB. Это технический smoke-тест, а не художественная приёмка.

## Где полноценная сборка и оригинальный MOTION RIG

Пользователю в чате передаётся самодостаточный ZIP `AI_ANIME_FACTORY_V502_CLEAN_CUTS_WINDOWS_REVIEW.zip` с:

- оригинальным `SOURCE/motion_rig_v502.js`, который имеет SHA256 `6f569e3974143544ce208e8653f201480242b7441effd6ea16f6454f3049d47f`;
- новым `SOURCE/clean_cuts_v502.js` и `AI_Anime_Factory_V50_2_MOTION_READY.html`;
- 13 оригинальными JPEG и проектом JSON с каноном, 6 эпизодами;
- двумя **новыми** MP4 по 70,5 сек и детальным русским README.

**Важно:** этот PR хранит исходник самого исправления и воспроизводимый скрипт его применения. 13 JPEG и весь первоначальный MOTION RIG ещё *не скопированы напрямую в GitHub*: полный исходник MOTION находится в архиве предыдущей V50.2. Не заявляйте, что один только PR позволяет построить готовый видеосериал без базового ZIP.

## Как воспроизвести патч из GitHub

```bash
python scripts/apply_clean_cuts_v502.py \
  --base-zip AI_ANIME_FACTORY_V502_MOTION_RIG_ART_WINDOWS_REVIEW.zip \
  --out AI_ANIME_FACTORY_V502_CLEAN_PATCHED_FROM_GITHUB.zip
```

Проверяется SHA256 оригинального MOTION RIG и неизменяемость исходной истории. Функция из GitHub возвращает только исправленную программу, сохраняя прежние MP4; новые перерендеренные видео включены в готовый ZIP из текущего чата.
