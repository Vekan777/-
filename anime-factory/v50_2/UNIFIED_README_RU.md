# AI Anime Factory V50.2 UNIFIED — полный исходный MOTION RIG и ART

**Статус: технически проверяемый 2D-пилот, художественно НЕ принят.**
Это продолжение той же V50.2, а не V51/V52 и не «полный профессиональный сериал».

## Что нового именно в этой сборке

Сборка теперь **полностью воспроизводима из ветки GitHub**:
- оригинальный большой файл \`motion_rig_v502.js\` (все суставы, стопы,
  оружие, шесть вариантов костюма), а не сокращённый макет;
- оригинальные **13 бинарных JPEG**, отдельно проверяемые по SHA256,
  хранятся прямо в \`anime-factory/v50_2/art/\`;
- настоящий V50.2 DIRECTOR, V50.1 и весь V19–V50 HTML остаются основой;
- \`clean_cuts_v502.js\`: убраны двойные полупрозрачные портреты,
  сохранён размер лица в кадре, режим переключается;
- исходник \`build_complete_v502.py\` воспроизводит автономный
  редактор и может встраивать сюжетный JSON на первый запуск;
- \`test_v502_complete_unified.py\` проверяет сохранность всех шести
  эпизодов, двух полных пилотных сценариев, 13 JPEG, 12 сцен,
  10 фаз боя, реверсивное включение CLEAN CUTS;
- MP4 создаются реально, НЕ имитируются статическими заглушками,
  а исходный проект JSON не перезаписывается.

Техническая проверка не является экспертной оценкой движения,
монтажа или качества озвучки. Нельзя обещать студийную графику,
полные 20–40-минутные серии или лицензированную актёрскую речь.

## Запуск Windows 10 64-bit

1. Извлечь Windows ZIP **в отдельную папку**, не поверх V50 или V50.1.
2. Открыть \`RUN_WINDOWS.bat\` или HTML \`AI_Anime_Factory_V50_2_UNIFIED.html\`.
3. При первом запуске без старых данных пилотный JSON встроен, когда
   архив собран с опцией \`--project\`. При наличии старых данных
   редактор уважает предыдущую версию. Для ручного открытия:
   импортировать \`PROJECT_V502_UNIFIED.json\`.
4. В V50 финальной панели убедиться, что включены
   **DIRECTOR, ART PASS, MOTION RIG и CLEAN CUTS**.
5. Для 2D-просмотра подходят маломощный ноутбук i7-3630QM, 8 GB,
   Windows 10 64 bit; режимы 640×360, 6 FPS. Это не студийные 24 FPS.

## Экспорт двух русских MP4

- Python 3.11+, \`SETUP_WINDOWS.bat\` — установить Playwright Chromium.
- FFmpeg: уже загруженный пользователем архив
  \`ffmpeg-9.0.2-full_build.zip\` (не нужно скачивать повторно).
  Извлечь \`ffmpeg.exe\` и \`ffprobe.exe\` в \`tools\ffmpeg\bin\`.
- Открыть \`RENDER_2_RU_MP4_WINDOWS.bat\`; дождаться появления
  \`NEW_EPISODES/episode_01.mp4\` и \`episode_02.mp4\`.
  На старом CPU процесс может быть медленным.
- MP4 используют черновую русскую озвучку eSpeak NG. Записи
  разных актёров можно подставить через \`postprocess_v502.py\`
  в порядке 24 WAV-фрагментов; нужна явная проверка прав,
  доступной длительности и выразительности.

## Повторение сборки на GitHub / Linux

\`\`\`bash
python anime-factory/v50_2/build_complete_v502.py --selftest
python anime-factory/v50_2/build_complete_v502.py \
  --project dist/V502/PROJECT_V502.json \
  --out dist/AI_Anime_Factory_V50_2_UNIFIED.html
python tests/test_v502_complete_unified.py \
  --html dist/AI_Anime_Factory_V50_2_UNIFIED.html \
  --out dist/V502/UNIFIED_QA
python scripts/package_v502_unified_windows.py \
  --html dist/AI_Anime_Factory_V50_2_UNIFIED.html \
  --project dist/V502/PROJECT_V502.json \
  --out dist/AI_ANIME_FACTORY_V502_UNIFIED_WINDOWS.zip
\`\`\`

Для первого построения исходного пилотного JSON запускайте
\`scripts/produce_2d_pilot_v501.py\` с \`--tts\` и затем
\`scripts/postprocess_v502.py\`: сценарий не теряется,
а записи речи и FX попадают в переносимый JSON.

## Что необходимо для художественного завершения 2D

Осталось существенно переработать анатомию и детализацию
многослойных персонажей, актёрскую мимику, боевые удары
(контакт, вес, последствия), последовательность света/цвета
между общими и крупными планами, естественную русскую
озвучку с её правами, музыку, монтаж и все эпизоды сезона.

Художественная приёмка по-прежнему **НЕ пройдена**.
Первоначальный сюжет V19–V50 и шесть эпизодов неизменны.
Никакого перехода на 3D Edition до готовой 2D основы.
