# V50.2 ART PASS — художественный тест, не финальный 2D

Этот patch продолжает **V50.2**, не создавая V50.3/V51 и не
меняя оригинальные сюжетные данные V19–V50.2.

Что реально выполнено в экспериментальной пользовательской сборке:

- 13 оригинальных сгенерированных иллюстративных фрагментов
  (Акира, Мию, Рэн, Сайра, страж, бой, мир, портал и эмоции)
  импортированы в **самодостаточный HTML**; изображение не требует
  интернета и не берётся из сторонних аниме.
- Добавлено отображение картинок как **неподвижных крупноплановых
  вставок** поверх исходной 2D-анимации, с панорамированием,
  затемнением и мягкими переходами. Это не покадровая анимация.
- Русская черновая озвучка, исходные данные сцен, субтитры,
  музыка, боевые эффекты и запись MP4 из V50.2 сохранены.
- Добавлен переключатель ART PASS с возвратом к предыдущему
  V50.2, без перезаписи старых сцен.
- Для подтверждения созданы три видеоклипа по 8 секунд
  на основе реальных кадров программы; русская звуковая
  дорожка из технически проверенного MP4 V50.2.
- Проверено в headless Chromium (13/13 картинок загрузились,
  глубокая техническая QA сохранила ноль ошибок) и FFprobe
  (тестовый 24-секундный MP4, H264/AAC).

ОГРАНИЧЕНИЯ: смешивание иллюстрации и старого векторного тела
выглядит неравномерно. В бою старые пропорции остаются слишком
упрощёнными. Время записи/анимации не изменено: это **не два новых
40-минутных эпизода** и не уровень профессионального студийного
сериала. Права на использование сторонних актёрских голосов
не подтверждены, временные eSpeak остаются роботизированными.
Ни графика, ни музыкальное сопровождение, ни сюжетный сезон
не имеют художественной приёмки.

GitHub содержит исходник \`art_pass_preview.js\`, который принимает
\`window.v502IllustrationData\` (название файла => base64 JPEG).
Сами реальные 13 JPEG и готовый HTML упакованы **в ZIP, выданный
пользователю отдельно**, потому что бинарные материалы не были
загружены в репозиторий. Нельзя считать одну GitHub-ветку
самодостаточной без ART ASSETS.

Запуск пользовательского Windows-архива:
1. Распаковать в отдельную папку, запустить \`RUN_WINDOWS.bat\`.
2. Восстановить \`PROJECT_V502_ART_PASS.json\`.
3. В «ФИНАЛЬНАЯ QA V50» включить режиссуру V50.2 и ART PASS.
4. Сравнить иллюстрированные планы с исходной анимацией.
5. Для MP4 использовать \`render_anime_v48.py\`,
   Python, Playwright Chromium и FFmpeg; подробная команда — в ZIP.

Задача оставшегося *единственного финального художественного этапа*:
отрисованные многослойные персонажи для всех ракурсов, реальная
анимация лица/рук/ног/клинков, последовательные боевые сцены,
24 лицензированные выразительные русские реплики, полноценное
сведение звука, контроль причинности сюжета, внешняя ручная
проверка кадров и публикация только после письменной приёмки.
