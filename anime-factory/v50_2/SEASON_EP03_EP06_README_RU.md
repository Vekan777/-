# AI Anime Factory V50.2 — сценарии серий 3–6 и проверка непрерывности

**Статус:** готова рабочая сценарная раскадровка шести коротких пилотов. **Не готов художественный сезон** и нет профессиональной актёрской озвучки.

## Исправлено в этой работе

Серии 1–2 «Сигнал Разлома» и «Старый друг» вообще не перезаписываются скриптом `expand_season_v502.py`. Хэш их данных проверяется до и после. Все исходные фразы и схемы сцен 3–6 также сохраняются в `sourceSceneTextV19`, а исходные события — в `pilotV50.sourceStoryV20`.

Серии 3–6 получили **24 подробные сцены, 48 русских реплик, режиссёрские планы, описание актёрской игры, места действия, улику, развязку, травму и дневник памяти**. Никакого автоматического оправдания Рэна: предательство мотивировано пленением сестры, но последствия остаются.

Шесть уникальных необратимых утрат памяти:

1. Дом детства — серия 1.
2. Первая встреча с Мию — серия 2.
3. Имя старого наставника — серия 3.
4. Слова собственной клятвы — серия 4.
5. Голос матери — серия 5.
6. Воспоминание о начале дружбы с Рэном — серия 6.

Таким образом, исправлен предыдущий сюжетный дефект, где серия 6 повторно отнимала уже утраченное в серии 1 воспоминание о доме. **Вернуть память через дневник нельзя:** дневник сохраняет факты, а не переживание.

`season_stage_v502.js` подключает серии 3–6 к существующему режиссёру и MOTION RIG: в кадрах будут соответствующие роли, а не всегда одинаковая пара. Задействованы прежние 13 иллюстраций; их недостаточно для студийной покадровой анимации, поэтому режим художественно не принят. В сценах с эффектом призыва доступны ранее разработанные ограничения движения и цены силы.

## Сборка

```bash
# В исходной V50.2 от GitHub уже есть сценарные серии 1–2 и русские MP3:
python scripts/expand_season_v502.py \
 --project dist/V502/PROJECT_V502.json \
 --story anime-factory/v50_2/STORY_EP03_EP06_V502.json \
 --out dist/V502/PROJECT_SIX_EPISODES.json \
 --tts --sound

python anime-factory/v50_2/build_season_v502.py \
 --project dist/V502/PROJECT_SIX_EPISODES.json \
 --out dist/AI_Anime_Factory_V50_2_SIX_EPISODES.html

python tests/test_season_v502.py \
 --source dist/V502/PROJECT_V502.json \
 --project dist/V502/PROJECT_SIX_EPISODES.json \
 --html dist/AI_Anime_Factory_V50_2_SIX_EPISODES.html \
 --out dist/V502/SEASON_QA

python scripts/render_six_pilots_v502.py \
 --html dist/AI_Anime_Factory_V50_2_SIX_EPISODES.html \
 --project dist/V502/PROJECT_SIX_EPISODES.json \
 --episodes 3,4,5,6 --width 640 --fps 6 --out dist/V502/VIDEO
```

При запуске нужен `espeak-ng` (только для создания временных черновых речевых файлов), `ffmpeg`, Python и Chromium через Playwright. Для MP4 понадобится больше времени и ресурсов. В пользовательском Windows ZIP будут вложены уже подготовленные JSON и видео, поэтому при обычном просмотре пользователю не нужно устанавливать синтез речи.

## QA / красные флаги

- Все шесть сценариев имеют шесть сцен, 72 реплики и шесть неповторяющихся потерь памяти.
- В 3–6 сериях диалоги должны быть синхронизированы по фактической длительности двух WAV, без выдуманного фонемного липсинка.
- `productionV50.qaAccepted=false` и все художественные/лицензионные галочки остаются **false**.
- Движение сустава и крупные планы являются **техническим аниматиком**. Профессиональных изображений на каждый кадр, чистых анимационных слоёв и естественных российских актёрских голосов пока нет.
- Сюжетный «финал» шестой серии завершает **первую арку**, но не весь многосерийный сериал. Не заявлять готовность сезона к публикации.

**Никакой автоматической замены исходных проектов: все выходные файлы создаются рядом с оригиналами.**
