AI Anime Factory V50.2 — PERFORMANCE PASS: 6 технических аниматиков

Статус: НЕ художественная финальная приёмка.

Изменения: эмоциональные варианты портретов и лёгкое движение камеры для эпизодов 3–6; переключаемая атмосфера всех шести эпизодов, световые следы ударов и повествовательные частицы. Данные сюжета, аудиодорожки и прежний рендер сохранены. Художественные JPEG остаются неподвижными: настоящее анимирование лиц, ротов, конечностей и полноценный skinning отсутствуют. Русский голос eSpeak NG остаётся роботизированным.

WINDOWS 10
1. Распаковать полный архив в новую папку.
2. Открыть RUN_WINDOWS.bat и импортировать PROJECT_V502_UNIFIED.json при необходимости.
3. Проверить включение DIRECTOR, ART PASS, MOTION RIG, CLEAN CUTS, SEASON STAGE и PERFORMANCE.
4. Для рендера поставить Python 3.11+, Playwright Chromium, использовать ранее имеющийся FFmpeg 9.0.2, затем RENDER_6_RU_WINDOWS.bat.
5. На ноутбуке i7-3630QM, 8 ГБ, GT740M сначала использовать 640×360 при 6 FPS.
6. Всегда экспортировать JSON вручную после изменения: размер проекта может превысить localStorage.

Тесты: 18 кадров из шести эпизодов, 13 JPG, сюжетная SHA, русская речь + музыка + эффекты, отключение эффекта, контроль чёрных кадров. В CI проверяется реальная запись шести коротких MP4. Данный smoke-тест не подтверждает качество уровня коммерческого аниме. Требуются профессиональные персонажи, полноценная анимация, постановочные бои, права на голоса и человеческая художественная приёмка.
