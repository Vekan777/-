# AI Anime Factory V50.2: отдельный реальный рендер 960×540, 12 FPS

Это всё ещё V50.2 — **не новый номер** и не художественно готовый сериал. Добавлен скрипт
\`scripts/render_v502_offline.py\`, который снимает **новые настоящие кадры**
из Canvas проекта: 960×540 @ 12 кадров/с (вместо прежнего 640×360 @ 6 кадров/с).

Он не увеличивает старый MP4 и не использует его как источник звука.
Для каждой из первых двух серий берутся из оригинального JSON 18 отдельных
MP3-фрагментов: по шесть дорожек \`voice\`, \`music\`, \`fx\`, все присутствуют
в переносимом проекте. Их смещение определено хронометражем V35; музыка
автоматически приглушается во время русской речи, сохранены отдельные звуковые
эффекты и источники субтитров V37. Видео записывается потоком PNG в FFmpeg,
не накапливая тысячи кадров в оперативной памяти.

Полнота истории: шесть эпизодов, два сценарных пилота по шесть сцен,
два говорящих в каждой сцене, отпечаток V19–V50. Совместимый откат к
прежней V50.2. Абсолютно никакой автоматической художественной приёмки.

## Запуск в Windows

Рекомендуется для более мощного компьютера. На старом ноутбуке i7-3630QM,
8 GB RAM можно выбрать \`--fps 6 --width 640\`, поскольку 960/12 заметно
нагружает CPU. Требуются Python 3.11+, FFmpeg с FFprobe и Chromium Playwright.

Если \`render_v502_offline.py\` находится в новом Windows ZIP — можно запустить
\`RENDER_HD_12FPS_WINDOWS.bat\`, предварительно положив два исполняемых FFmpeg
в \`tools\ffmpeg\bin\`. Скрипт устанавливает \`numpy\` и \`playwright\` через
pip и Chromium через Playwright, но установка требует доступа к интернету.

Ручная команда:

\`\`\`powershell
py -3 -m pip install numpy playwright==1.56.0
py -3 -m playwright install chromium
py -3 render_v502_offline.py --html AI_Anime_Factory_V50_2_UNIFIED.html --project PROJECT_V502_UNIFIED.json --out NEW_HD_VIDEO --episodes 1,2 --fps 12 --width 960
\`\`\`

Файлы результата: \`episode_01.mp4\`, \`episode_02.mp4\`, два SRT, образы
кадров для контроля и \`V502_OFFLINE_RENDER_QA.json\`.

## Что не решает 12 FPS

Исходные 13 JPEG имеют небольшие размеры; увеличение разрешения рендера
НЕ добавляет им потерянную детализацию. Крупные планы остаются
иллюстрированными статичными вставками с движением камеры, а боевые
суставные фигуры всё ещё схематичные. Черновая TTS-речь eSpeak — не
естественная актёрская игра, точной фонемной анимации лица нет.
Не выдавать эти тестовые эпизоды за готовые профессиональные серии или
за полностью завершённый 2D-сезон.

Артефакты GitHub Actions хранят реальные кадры, кодеки, длительности и
отчёты, пока не истёк срок их хранения. Художественная и правовая
экспертиза остаётся обязательной.
