# AI Anime Factory V40 — Character Art & Drawing Quality

Новая **V40** добавляет художественные детали непосредственно в существующий процедурный 2D-риг. Сохранены оригинальная V19 и модули V20–V39: история, персонажи, сцены, исходы боёв, V35 монтаж, V36 звук/видео, V37 субтитры, V38 камера/цвет, V39 физика движения.

## Что действительно добавлено

- **Глаза и лицо:** новые радужки, блики, зрачки, брови и мягкий цвет щёк. Веки связаны со старыми событиями моргания, эмоциями и взглядом V13/V39.
- **Волосы:** дополнительные оформленные пряди и блики, двигающиеся вместе с головой и исходной анимацией волос.
- **Костюм:** контурные плечевые элементы, швы, складки, декоративный воротник и брошь в тех же локальных координатах, что исходный 2D-риг.
- **Параметры персонажа:** выразительность глаз, детализация волос, костюма, контуров и бликов плюс профили «Кинематографичный», «Чистая аниме-линия», «Фэнтези».
- **Настоящий сравнительный предпросмотр:** два изображения одной сцены и одного времени с отключённой и включённой рисовкой V40, четыре контрольных PNG и JSON параметров.
- Новые данные сохраняются только в **`character.visualV40`**. История, вид героя V23, звуковые файлы, длительности и события боя не переписываются.
- Настоящий WebM со звуком записывается прежним V36 MediaRecorder: в него попадают все активные новые детали рисунка V40.

## Запуск Windows 10 (64-бит)

1. Скачайте V40 Windows ZIP по постоянной GitHub-ссылке либо в разделе Releases. Распакуйте **полностью в новую папку**, не поверх V35–V39.
2. Запустите **`RUN_WINDOWS.bat`** или откройте `AI_Anime_Factory_V40_CHARACTER_ART.html` в Chrome/Edge. Python для открытия HTML не нужен.
3. В «Аудит V30» сначала экспортируйте **полную резервную копию проекта JSON**. V40 автоматически подхватывает сохранённый проект V39 из того же браузера.
4. Откройте вкладку «**Рисовка V40**». Выберите персонажа и стиль, настройте глаза, волосы, контуры, детали костюма и блики.
5. Нажмите «Сохранить художественный стиль персонажа», затем сравните **до/после** при одинаковом таймкоде; переключите сцену через остальные редакторы при необходимости.
6. Скачайте четыре настоящих кадра PNG и JSON художественных настроек. Нажмите «Проверить рисовку»; замечания не являются художественной экспертизой.
7. Для фильма со звуком откройте вкладку «Звук / экспорт V36» и снова подключите свои WAV/MP3/OGG, если браузер перезапущен. Нажмите «Записать V40 с улучшенной рисовкой» — будет скачан настоящий WebM.
8. Для MP4 положите WebM рядом с `CONVERT_MP4_WINDOWS.bat` или перетащите WebM на BAT. Утилита требует **FFmpeg**: `ffmpeg.exe` в PATH или `tools/ffmpeg/bin/ffmpeg.exe`; можно использовать ваш прежний `ffmpeg-9.0.2-full_build.zip` после распаковки.
9. Сохраните полный JSON после правок; аудиофайлы необходимо хранить отдельно (они не встроены в проектный JSON).

### Характеристики компьютера

Для Windows 10, 8 ГБ RAM и GT740M лучше начать с **640×360, 6 FPS** и короткого эпизода. Эта версия остаётся **процедурным 2D-аниматиком**. Рисовка V40 не является настоящей 3D-моделью, не перерисовывает импортированные авторские PNG и не обещает студийную покадровую анимацию. Качественный результат оценивается по кадрам и человеческому художественному ревью.

CI на Windows, Linux и Chromium проверяет источник V19, поведение прежнего V39, сохранение ключевых полей проекта, различие настоящих пикселей кадров V40 «до/после», наличие аудио и видео в WebM, SHA256 и CRC32 ZIP, объединение V7 и русскую инструкцию.
