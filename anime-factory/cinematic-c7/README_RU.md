# AI Anime Factory — CINEMATIC C7 UNIFIED (3D + Russian TTS)

Текущая техническая версия: `CINEMATIC_C7_STANDALONE.html` — **реально запускаемый автономный HTML** с оригинальными 3D-персонажами GLB (14 костей, ~3750 треугольников каждый), анимацией скелета через glTF JOINTS_0/WEIGHTS_0 и инверсные bind-матрицы, постановкой боёв C4/C5 и студией серий C6.

- [Запустить/скачать автономный HTML C7](./CINEMATIC_C7_STANDALONE.html). В Chrome/Edge откройте скачанный HTML как файл, интернет и сервер не нужны. WebGL может не работать на слабом драйвере — имеется резервный CPU 3D-рендер.
- Импортируется **GLB 2.0 с skinning**, до 4 МБ, 60 костей и 35 тыс. треугольников. Поддержка сложных текстур/расширений, морфов и некоторых анимаций пока неполная.
- **Русский синтез речи для итогового MP4** выполняется приложенными в полной Windows ZIP утилитами `batch_render_c7.py` + `voice_pipeline_c7.py`, если установлен бесплатный eSpeak NG либо Piper с русской голосовой моделью. Аудиозаписи пользователей загружать необязательно. Браузерный speechSynthesis предназначен только для прослушивания.
- Исторические версии C1–C6 целиком входят как неизменённые ZIP в Windows-пакет C7, который выдаётся в ChatGPT; старые версии не перезаписывались.
- Весь C7 Windows пакет, тестовый MP4 с русской речью и подробная инструкция доступны в текущем диалоге как прикреплённые файлы. Пакетный рендерер и Python-скрипты **на GitHub пока отдельно не загружены**.
- Линия [V19–V50](../v50/README_RU.md) сохранена отдельно; полноценный совместимый импорт **не завершён**.

**Ограничения и художественная честность:** C7 — рабочий 3D-аниматик, не качество Solo Leveling/A-1 Pictures. Созданные модели стилизованные low-poly, eSpeak звучит роботизированно. Нет подтверждённого 24-минутного выпуска и художественной приёмки. Далее — фиксированная **C8 DEEP QA FINAL** для доработки визуала, сцен, голоса, лиц, материалов и углублённой проверки.
