# AI Anime Factory C6 — Episode Production

C6 produces multi-scene procedural **3D animatics**, not studio-quality anime.

The working C6 standalone HTML, nine JS modules and modular editor are preserved in this folder. [Open autonomous HTML](CINEMATIC_C6_STANDALONE.html) in Chrome/Edge.

Episode editor: 12 episodes, up to 120 scene clips per episode, separate C5 source project per clip, editor of timeline/camera/motion/subtitles, JSON save/restore, full-episode SRT export. The C1–C5 scene data is retained in nested JSON payloads.

**The downloadable C6 Windows ZIP in the ChatGPT conversation also contains the Python Playwright+FFmpeg batch renderer** for multi-episode MP4 H.264/AAC, test fixtures, batch scripts, checkpoint/resume SHA-256 reports and Russian launch instructions.

Validated: 2 technical episodes with two cuts each (1.5 seconds per episode), H.264 video and AAC audio, Chromium editor tests, source JSON preservation and checkpoint re-use. Studio-level faces, 3D skinning imported OBJ, professional Russian acting and final art are **not implemented**.
