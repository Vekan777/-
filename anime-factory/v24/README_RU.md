# AI Anime Factory V24 — Character Animation

**Текущая ветка:** V24, очередной слой поверх подлинного V19 и интегрированных V20–V23. До успешного GitHub Actions сборку нельзя называть окончательно проверенной.

## Реальные изменения
- Процедурная походка с шагом, подъёмом переносимой ноги и плавным переносом веса.
- Подготовка к атаке, положение рук и корпуса, инерция ткани и волос после движения.
- Реакция на попадание и блок по фактическим событиям `impact19State`, где они заданы. Без событий используется существующая процедурная постановка боя.
- Режиссёрские параметры каждой сцены: длина шага, вес, подготовка, отдача, инерция, режим `auto` / `cinematic` / `subtle`.
- A/B просмотр одного времени сцены — базовая анимация V23 и улучшенная V24 рядом. Настройки V24 влияют на штатный Canvas-рендер и экспорт, а не только на отдельную демонстрацию.
- Экспорт листа 4 PNG кадров и TXT-плана движения.
- Файл проекта сохраняет `motionV24` для каждого эпизода/сцены, прежние `actingV22`, `visualV21`, `qualityV23`, сюжет `storyV20`, канон и пользовательский арт.

## Запуск Windows 10
1. Скачайте ZIP с V24, когда GitHub Actions подтвердит Windows/Linux/Chromium тесты.
2. Распакуйте ZIP целиком в отдельную папку, затем откройте `RUN_WINDOWS.bat`.
3. Вкладка «Анимация V24» → выбор сцены → профиль → настройка ползунков → «Сохранить движение V24».
4. Скачайте JSON проекта в отдельную резервную папку и четыре PNG для сравнения.
5. Для MP4 отдельно потребуется FFmpeg. На ноутбуке с 8 ГБ RAM начните с 640×360, 6 FPS.
6. Для объединённого движка V7 выбирайте отдельный ZIP из GitHub Artifacts, он содержит и прежние версии.

### Контроль целостности
- Сборщик `anime-factory/v24/build_animation_v24.py` последовательно применяет V20/V21/V22/V23/V24 к оригинальному V19 без его перезаписи.
- `tests/test_anime_v24.py`: функции, исходники, миграция, JS-синтаксис и неизменность V19.
- `tests/smoke_browser_v24.py`: Chromium: A/B кадры, изменение ползунков, перезагрузка, сохранность V20–V24, экспорт PNG.
- `scripts/build_anime_v24.py`: создаёт ZIP и проверяет CRC32, контрольный SHA256 каждого файла, исходный V19 в backup.
- `scripts/build_v7.py`: собирает единый пакет с V24, V1–V6 и Anime V19–V23.

### Ограничения
Это процедурный 2D-аниматик без физического IK, захвата движений и фотореалистичного 3D. Импортированные пользовательские рисунки сохраняются, но модуль не деформирует их как готовых персонажей. Успешные автоматические проверки подтверждают техническую исправность, а не студийное качество готовой анимации.
