# AI Anime Factory V36 — Audio & Episode Export

V36 — **надстройка поверх реальной V35** с прежней визуальной временной шкалой, всеми сценами и сюжетом V19–V35. V35 и все предшествующие исходники остаются в репозитории без замены.

## Реализовано

- Для каждой сцены три дорожки: **речь**, **музыка**, **эффекты**. Аудиофайлы WAV/MP3/OGG загружаются пользователем с диска и декодируются браузером. Генерации голосов или музыки пока нет.
- Поле audioV36 содержит только метаданные: имя файла, усиление 0–2, сдвиг 0–120 секунд. Поля прежних сцен (duration, storyV20, storyboardV34, assemblyV35) **не изменяются**.
- План берётся через v35Plan. Web Audio API воспроизводит и смешивает дорожки по общей временной оси, с плавными переходами громкости между сценами. Музыка зацикливается на время сцены. Речь и эффекты играют один раз.
- Предпросмотр 640 × 360 синхронизирует Canvas v35Frame с часами AudioContext.currentTime.
- Экспорт записывает **реальные видео+аудио в WebM** с помощью canvas.captureStream, MediaStreamAudioDestinationNode и MediaRecorder **в реальном времени**. Файл скачивается в браузере.
- Для MP4 в ZIP включён CONVERT_MP4_WINDOWS.bat: использует локальный FFmpeg (tools/ffmpeg/bin/ffmpeg.exe или PATH) для H.264/AAC. FFmpeg **не вложен**.
- Экспорт JSON-плана аудиодорожек, аудит неподключённых файлов, ошибок сдвига и длительности.
- В ZIP — резерв подлинного V19, исходники V20–V36, BUILD_MANIFEST.json, SHA256 и CRC32.

## Windows 10 — запуск и звук

1. Скачайте ZIP V36 из GitHub Actions или Releases и полностью распакуйте в новую папку, не поверх V35.
2. Запустите RUN_WINDOWS.bat либо откройте AI_Anime_Factory_V36_AUDIO_EPISODE_EXPORT.html в Chrome/Edge.
3. В разделе «Аудит V30» сохраните полную резервную копию проекта JSON.
4. Перейдите в «Звук / экспорт V36»; выберите эпизод и сцену, дорожку и загрузите файл.
5. Задайте громкость, сдвиг (100 — одна секунда), сохраните. Повторите для нужных сцен.
6. Нажмите «Аудит звука», затем «Слушать + смотреть».
7. Нажмите «Записать и скачать WebM эпизода». Дождитесь окончания реального воспроизведения; не меняйте вкладку. Видео скачивается автоматически.
8. Для MP4 переместите скачанный WebM рядом с BAT и запустите CONVERT_MP4_WINDOWS.bat либо перетащите WebM на BAT.
9. Если FFmpeg отсутствует, распакуйте ранее скачанный ffmpeg-9.0.2-full_build.zip и поместите файл ffmpeg.exe в tools/ffmpeg/bin/ внутри V36 (создайте папки) или установите FFmpeg в PATH.
10. Сохраните исходные звуковые файлы рядом с резервным JSON отдельно от приложения.

**Ограничения:** локальные бинарные аудиоданные остаются только в памяти браузера. В JSON/HTML встроены только имена и настройки. После перезагрузки нужно снова прикрепить файлы. WebM — реальный фильм с доступным звуком; если дорожек нет, слышимого звука нет. MP4 требует FFmpeg. Для ноутбука 8 ГБ/GT740M рекомендуется 6 FPS. Экспорт не ускоренный. Это 2D-аниматик, не 3D.

## Проверки

- python anime-factory/v36/build_audio_v36.py --selftest
- python -m unittest discover -s tests -p "test_anime_v36.py" -v
- python scripts/build_anime_v36.py --selftest
- python anime-factory/v36/build_audio_v36.py --output dist/AI_Anime_Factory_V36_AUDIO_EPISODE_EXPORT.html
- python tests/smoke_browser_v36.py --html dist/AI_Anime_Factory_V36_AUDIO_EPISODE_EXPORT.html --out dist/V36_AUDIO_SAMPLES

Smoke-тест Chromium прикрепляет реальный WAV, проверяет JSON и поля V20–V35, затем скачивает настоящий WebM. При доступности ffprobe проверяются реальные аудио/видеопотоки и длительность. Технические тесты **не доказывают** художественное качество или отсутствие сюжетных противоречий.
