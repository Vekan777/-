# AI Anime Factory V42 — Stage Depth, Lighting & Atmosphere

Версия **V42** дополняет настоящую сборку V19–V41 кинематографическим окружением для процедурного 2D-аниматика. Она сохраняет сценарий, персонажей, события и исходы боя, V35 монтаж и кроссфейды, V36 звук и WebM, V37 субтитры, V38 движение камеры, V39 позы, V40 рисовку и V41 силуэты. Новый параметр сцены находится отдельно в `stageV42`.

## Что действительно работает

- **Три полупрозрачных слоя глубины**, которые смещаются с разной скоростью относительно камеры; не удаляют исходные декорации или персонажей.
- **Направленный свет**, тёплый рассвет, холодная гроза, искры и лунная ночь. Свет и дымка действительно меняют пиксели реального Canvas.
- **Ветер и атмосферные частицы**, привязанные детерминированно к таймкоду. Эффекты не требуют тяжёлой внешней нейросети или 3D GPU.
- **Каноническое освещение контакта боя** только при подтверждённом `hit` или `block` старой системы V25. V42 не придумывает удар, победу или изменение сюжета.
- Предпросмотр общей шкалы V35 и запись полученного изображения прежним V36 `MediaRecorder` с существующим звуком и субтитрами V37.
- Контрольный лист четырёх реальных PNG, JSON всех настроек сцены и аудит чрезмерно плотной атмосферы.
- Windows ZIP с исходным V19, предыдущим кодом V20–V41, вложенным полным V41 ZIP и проверенным манифестом SHA256/CRC32.

## Установка Windows 10 x64

1. Скачайте `AI_ANIME_FACTORY_V42_STAGE_DEPTH_WINDOWS.zip` по прямой постоянной ссылке GitHub или из Releases, полностью распакуйте в **новую папку**, не заменяя V35–V41.
2. Дважды нажмите `RUN_WINDOWS.bat`, либо откройте `AI_Anime_Factory_V42_STAGE_DEPTH.html` в Chrome/Edge. Python для просмотра HTML не нужен.
3. Перед изменениями экспортируйте **полный резерв проекта JSON** на вкладке «Аудит V30». При использовании того же браузера V42 подхватывает сохранённый V41; при переносе используйте экспорт/импорт JSON.
4. На вкладке **«Свет и атмосфера V42»** выберите серию и сцену. Для начала выберите стиль `Рассвет`, `Гроза`, `Тлеющие угли` или `Лунная ночь`.
5. Отрегулируйте глубину, направленный свет, атмосферу, частицы и ветер. Нажмите «Сохранить постановку сцены».
6. Запустите предпросмотр эпизода. Для сравнения выключите галочку V42, сохраните, затем включите снова при **одинаковом таймкоде**. Скачайте четыре PNG и JSON.
7. Проверьте замечания аудита. Он выявляет слишком плотную атмосферу, но не определяет художественное совершенство кадра.
8. Для настоящего WebM со звуком перейдите в **«Звук / экспорт V36»**, прикрепите собственные аудиофайлы WAV/MP3/OGG (если редактор был перезапущен, нужно выбрать снова), затем нажмите «Записать V42 с атмосферой и светом». Запись идёт в реальном времени.
9. Для MP4 перетащите WebM на `CONVERT_MP4_WINDOWS.bat` либо запустите BAT. Требуется `ffmpeg.exe` в `tools/ffmpeg/bin/` рядом с BAT или в системном PATH. Подходит ранее полученный `ffmpeg-9.0.2-full_build.zip` после распаковки.
10. Сделайте итоговую копию полного JSON и сохраните свои звуковые файлы отдельно. Внутри проекта не хранятся двоичные записи аудио.

### Возможности и ограничения

V42 — **2D эффект глубины и освещения**, а не геометрический 3D-мир, не автоматически перерисованные аниме-персонажи и не нейросетевой кинорендер. Новые визуальные слои могут влиять на кадр поверх существующих рисунков; в рабочем проекте следует проверять читаемость персонажей и субтитров на реальном экране.

Для Windows 10, Intel Core i7-3630QM, 8 ГБ RAM и GT740M используйте сначала **640×360, 6 FPS**, короткие сцены и умеренное количество частиц. Для профессионального качества студийного аниме по-прежнему нужны профессиональные модели и анимационная система.

## Воспроизводимые проверки

```bash
python anime-factory/v42/build_stage_v42.py --selftest
python -m unittest discover -s tests -p "test_anime_v42.py" -v
python scripts/build_anime_v42.py --selftest
python anime-factory/v42/build_stage_v42.py --output dist/AI_Anime_Factory_V42_STAGE_DEPTH.html
python tests/smoke_browser_v42.py --html dist/AI_Anime_Factory_V42_STAGE_DEPTH.html --out dist/V42_STAGE_SAMPLES
```

CI автоматически выполняет Windows/Linux, Node.js синтаксис, реальную проверку Canvas, два типа света, сохранение прежних полей, FFprobe реального видео со звуком, CRC32/SHA256 и полный исторический объединённый V7.
