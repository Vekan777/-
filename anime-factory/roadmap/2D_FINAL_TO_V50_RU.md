# AI Anime Factory — окончательный план завершения 2D (V45–V50)

**Решение: осталось ровно шесть основных выпусков.** Текущая основа — опубликованная V44. Запрещено вводить V51, V52, … для продолжения 2D-функциональности. После V50 допускаются только исправления ошибок **V50.1, V50.2** без расширения технического задания. **3D Edition — отдельный продукт**, его план утверждается только после прохождения критериев готовности 2D.

## Что означает «готово под ключ»

Программа должна позволять **не программисту** создать законченный оригинальный 2D-аниме-эпизод: сценарий → герои → фоны → импорт/создание художественных материалов → скелетная/покадровая анимация → движения глаз и рта → диалоги/музыка → монтаж и титры → MP4/WebM + субтитры → проверка и резервная копия. Эпизоды должны объединяться в сезон с неизменяемой библией мира и последовательностью событий.

Полноценность рабочего производственного процесса **не означает гарантии профессионального рисунка без исходных материалов**. Для детализированного авторского аниме нужны оригинальные 2D-персонажи/фоны, ручная художественная проверка или подключённая генерация изображений (с правами на использование). В автономном режиме поставляется хотя бы один полностью законченный редактируемый демонстрационный набор; облачная генерация и голоса — **дополнительные режимы**, требующие законного доступа и, иногда, оплаты.

## Жёсткое правило версионирования

1. **Никаких промежуточных V45.5, V46.5 или новых V51** за новые функции. Пока соответствующий выпуск не прошёл определённый тест, исправляем его внутри той же ветки/PR и пересобираем.
2. За одну версию отвечает один ключевой результат. **Не тратим новые номера на инфраструктуру, текст, цвет, очередное меню или документацию.**
3. V49 — **единственная объединяющая версия** для 2D, V50 — **единственная финальная версия** после устранения ошибок. Исторические версии сохраняются в GitHub, но пользователь работает в одном V50.
4. V50 после финальной приёмки замораживается; любые багфиксы публикуются V50.1 и т. д. без новых функций. Затем готовим отдельную **3D Edition v1** и отдельное техническое задание под Godot/Blender (не просто переименовываем 2D в 3D).

## Приёмочный чек-лист V50 — ОБЯЗАТЕЛЬНО

- [ ] **Сценарий:** создана библия мира, логические связи, общие персонажи и **две связанные серии**; сюжетные факты/исходы боёв не меняются при импорте и рендере.
- [ ] **Персонажи:** минимум **2 узнаваемых полноразмерных 2D героя**, 3 выражения лица, раздельные слои рук/ног/глаз/рта; минимум 3 настоящие анимации с изменением геометрии.
- [ ] **Арт:** минимум 2 фона, работающая прозрачность PNG/WebP, импорт своих материалов и подтверждение лицензий; комплект автономной демонстрационной графики, а не кружочки-заглушки.
- [ ] **Движение:** ключи тела и лица, настоящие повороты/движения частей, проверка кадров до/после, проверенные таймкоды попаданий/защиты и согласованность камерных ракурсов.
- [ ] **Звук:** 2 голоса (или 2 независимо импортированных дорожки), музыка и эффекты; синхронизация рта с аудио; после закрытия/открытия проекта всё остаётся доступно без повторной загрузки.
- [ ] **Рендер:** 2 готовые серии, каждая содержит сцену диалога и анимации; минимум одна содержит бой. Есть настоящий MP4 (H.264/AAC при наличии законно установленного FFmpeg) либо понятный эквивалент/WebM, SRT/VTT и титры.
- [ ] **Стабильность:** тестируются JSON round-trip всех старых версий, повреждённые/отсутствующие файлы, неполная загрузка, сбой питания/перезапуск, отмена экспорта и возобновление проекта.
- [ ] **Windows под ключ:** `RUN_WINDOWS.bat` и понятный запуск без программирования; проверка на Windows 10 x64 с 8 ГБ ОЗУ, ограничение рабочей памяти и адекватный пресет 640×360 6–12 FPS, возможность более высокого качества на мощном ПК.
- [ ] **Безопасность/права:** не храним API-ключи открытым текстом в проектном HTML/ZIP, не исполняем непроверенные файлы, проверяем права на рисунки, музыку и голоса.
- [ ] **Никаких ложных обещаний:** автоматические тесты **не подтверждают художественное качество**. Требуется ручной просмотр демо-серии с персонажами, голосом, сценами и полноценным сюжетом.

**Итоговый поставляемый комплект V50:** `AI_ANIME_FACTORY_2D_FINAL_V50_WINDOWS.zip`, постоянная GitHub Releases и прямая ссылка, полный офлайн HTML/GUI, приложение для рендера, проектный шаблон и готовый демонстрационный аниме-эпизод, ассеты с указанием прав, автопроверка, резерв и восстановление, инструкции для Windows/FFmpeg/опционального ИИ, результаты тестов и реальное видео.

## После 2D: отдельный этап 3D

**3D Edition v1 начинается только после подписанного/проверенного чек-листа V50.** Из 2D переносятся: сценарная библия, герои и отношения, диалоги, таймкоды, события боя, музыка, титры и полезные художественные референсы. Не выдавать 2D спрайты за готовые 3D-модели: для 3D заново нужны меши/материалы, скелеты, анимации, свет, сцены и оптимизация для Windows/Android. Размер и план 3D определяются отдельно после работающего финального 2D.

**Контроль изменений:** [V44 базовая версия](https://github.com/Vekan777/-/releases/tag/anime-factory-v44) и документ `AUDIT_V44_TO_2D_FINAL_RU.md`. Любая новая задача должна попадать в V45–V50, а не создавать новую версию.
