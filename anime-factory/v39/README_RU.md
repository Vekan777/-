# AI Anime Factory V39 — Character Action & Performance

Версия V39 действительно меняет **движение процедурного 2D-рига персонажей**, а не только настройки монтажа. Она построена поверх V38 и сохраняет все исходные данные и модули V19–V38, включая сюжет, боевую разметку V17/V19, V35 таймлайн, V36 звук, V37 субтитры и V38 цвет/камеру.

## Новое в V39

- Точное дополнение к действующим V24 суставным движениям: корпус, плавные шаги, кисти, реакция головы, ткань и волосы. Движение вычисляется из текущего таймкода сцены детерминированно, а не приблизительной накопительной симуляцией.
- Улучшение существующих мимических выражений V13/V33: брови, глаза, моргание и ответная реакция. Лицо корректируется для уже существующей роли (герой/соперник), не меняя характер и сюжет.
- Для боевых сцен добавляется выразительность фаз: подготовка, выпад, ответная реакция, инерция. Эффект попадания рисуется только если V25Contact подтверждает **hit**, эффект защиты — только при **block**, уклонение — только при **dodge**. **Miss** не становится попаданием.
- Настройка по сценам: энергия движения, мимика, подготовка, инерция, эффект удара, линии скорости. Кнопки для пресетов, сохранения, аудита и экспорта настоящих кадров PNG.
- Настоящий видеорендер V39 интегрирован в прежнюю запись WebM с аудио V36, субтитрами V37 и цветокоррекцией V38.
- Сборка верифицируется SHA256/CRC32, содержит оригинальный V19, исходники V20–V39 и архив V38 целиком как резерв.

## Установка и запуск Windows 10 x64

1. Скачайте Windows ZIP V39 из постоянной папки `downloads/` GitHub или GitHub Releases. Распакуйте **полностью в новую папку**. Старые V35–V38 не удаляйте.
2. Запустите `RUN_WINDOWS.bat` либо откройте `AI_Anime_Factory_V39_CHARACTER_ACTION.html` в Chrome или Edge. Для запуска одного HTML не требуется Python.
3. На вкладке «Аудит V30» сохраните резервную копию полного проекта JSON. В V39 будет автоматически доступен сохранённый V38 из того же браузера; при переезде между компьютерами используйте экспорт/импорт проекта.
4. Откройте вкладку **«Персонажи и бой V39»**. Выберите серию и сцену. В первую очередь проверьте именно боевую сцену с персонажами.
5. Настройте энергию движения, мимику, подготовку и инерцию, эффекты удара и линии скорости. Для начала нажмите «Пресет для сцены», затем **«Сохранить движения и экспрессию»**.
6. Сравните переделанную боевую сцену с отключённой галочкой V39 (выключите/включите и сохраните). Создайте контрольные 4 PNG кадра, проверьте таймкоды и замечания аудита.
7. Для видео откройте «Звук / экспорт V36». Повторно приложите собственные аудиофайлы WAV/MP3/OGG, если браузер перезапускался. Нажмите кнопку **«Записать V39 с движением персонажей»**.
8. Браузер сохранит реальный WebM со звуком, субтитрами и движением. Запись идёт в реальном времени. Не закрывайте окно, пока запись не закончится.
9. Для MP4 используйте `CONVERT_MP4_WINDOWS.bat` с локальным FFmpeg (исполняемый `ffmpeg.exe` из предыдущего `ffmpeg-9.0.2-full_build.zip`, помещённый в `tools/ffmpeg/bin/ffmpeg.exe`, либо в системном PATH).
10. Сохраните полный JSON проекта после работы. Исходные WAV/MP3/OGG **не встроены** в JSON/HTML, поэтому храните их отдельно.

### Рекомендации по вашему ноутбуку

Для 8 ГБ RAM и GeForce GT740M рекомендуется **640×360 и 6 FPS** при записи. Не пытайтесь одновременно запускать тяжёлый Blender-рендер в фоне. Пробуйте сначала 1–2 короткие сцены и измеряйте качество воспроизведения.

### Ограничения без преувеличения

V39 — **2D-аниматик с процедурными персонажами**, а не реальная 3D-анимация или покадровая анимация студийного уровня. Изменения суставов работают на встроенном процедурном риге; пользовательские импортированные PNG слои остаются без автоматического риггинга и могут не реагировать на суставные настройки. V39 **не генерирует** новые голоса, персонажей, сценарные победы или авторские рисунки. Автотесты гарантируют проверенные технические свойства, но не художественный уровень результата.

### Проверка целостности и реального результата

- `python anime-factory/v39/build_performance_v39.py --selftest`
- `python -m unittest discover -s tests -p "test_anime_v39.py" -v`
- `python scripts/build_anime_v39.py --selftest`
- `python anime-factory/v39/build_performance_v39.py --output dist/AI_Anime_Factory_V39_CHARACTER_ACTION.html`
- `python tests/smoke_browser_v39.py --html dist/AI_Anime_Factory_V39_CHARACTER_ACTION.html --out dist/V39_ACTION_SAMPLES`

В GitHub Actions запускаются Node.js, Windows/Linux, Chromium, настоящие скриншоты PNG, изменения пикселей при переключении модуля, экспорт WebM с аудио и FFprobe, проверки сохранения канона и сборка объединённого V7. Сохраняются все тесты предыдущих версий.
