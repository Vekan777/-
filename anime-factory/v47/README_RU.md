# AI Anime Factory V47 — Voice & Lip Sync Engine

**V47 — третья из шести запланированных версий 2D-проекта V45–V50.** Главная цель: реальные WAV/MP3/OGG-файлы голоса, музыки и эффектов не исчезают после перезапуска редактора, а движение рта привязано ко времени звучания голоса.

## Реализовано и честные границы

- Аудиофайл выбранной сцены **сохраняется целиком как data:audio/...;base64 внутри `scene.audioV36.voice|music|fx.embeddedV47`**, вместе с рисунками, сюжетом, персонажами, боевыми событиями и V46 ключами. Полный переносимый JSON скачивается отдельной кнопкой.
- **После перезагрузки** сохранённый клип автоматически декодируется при запуске V36 предпросмотра или WebM-экспорта; не нужно выбирать тот же файл вновь.
- **Реальный уровень громкости** звукового сигнала считывается из PCM через Web Audio и записывается в `waveV47` с частотой 50 отсчётов/с. Во время анимации сцены рот персонажа открывается по настоящему аудио в правильном таймкоде с учётом задержки. Векторное лицо использует прежний механизм mouth(), а импортированная PNG-маска лица получает отдельный нарисованный овал рта с настраиваемым положением.
- Отдельные регулируемые громкости 0–200% и сдвиг звука для **трёх слотов**: голос, музыка и эффекты. Системы микширования/кроссфейдов V36 сохраняются.
- **Один персонаж-говорящий на один голосовой файл в каждой сцене**: если несколько участников говорят по очереди, используйте отдельные сцены или дальнейшую ручную дорожку. Этот предел нельзя выдавать за готовую озвучку сразу всей сложной сцены.
- Сохранены все прежние функции V19–V46, V35 длительности, V36 MediaRecorder, V37 субтитры, V45 арт-слои и V46 клипы.

**Важно:** звук управляет амплитудой открытия рта. Это *не* полноценный фонемный/виземный распознаватель речи. Невозможно гарантировать, что конкретная произнесённая буква будет изображена верной формой рта; это задача более развитого рига или ручного редактирования. Автоматическая синтезированная озвучка по тексту тоже не выдаётся за полноценную студийную — настоящие голосовые файлы должны быть предоставлены законным способом.

## Windows 10 x64: установка и запуск

1. Загрузите `AI_ANIME_FACTORY_V47_PORTABLE_VOICE_WINDOWS.zip` из GitHub Releases или папки `downloads/` и **полностью распакуйте в новую папку**. Не заменяйте ранее проверенный V46.
2. Откройте `RUN_WINDOWS.bat` двойным щелчком либо запустите `AI_Anime_Factory_V47_PORTABLE_VOICE.html` в Chrome/Edge.
3. На вкладке «Аудит V30» экспортируйте старый полный JSON до изменений. V47 попытается восстановить локальный проект V46, если открыт в том же браузере.
4. Откройте «**Озвучка и губы V47**», выберите эпизод, сцену и тип звука: голос, музыка или эффекты.
5. Нажмите «Загрузить переносимый аудиофайл». Поддерживаются WAV/MP3/OGG/WebM/M4A, если их декодирует браузер. **Размер одного файла не больше 1,5 МБ**: лучше выбрать сжатые OGG/MP3, а для длинной речи разбить её на небольшие сцены. 
6. Для голоса выберите персонажа, произносящего реплику; настройте громкость, задержку, включите «движения рта по реальному уровню звука». При PNG-маске лица отрегулируйте X/Y положения дополнительного рта; сохраните настройки.
7. Используйте ползунок времени на той же вкладке: виден текущий кадр и вычисленная амплитуда открытия рта. Если вместо аудио выбран неверный говорящий или время вне диапазона записи — рот останется закрытым.
8. Во вкладке «Звук / экспорт V36» запускайте **настоящий WebM** с видеодорожкой и загруженными voice/music/fx. Звуковые файлы автоматически распаковываются из проекта перед запуском после перезагрузки страницы.
9. Кнопка «**Полный JSON со звуками и рисунками**» сохраняет автономный переносимый проект. Скачайте файл на компьютер: браузерный localStorage не предназначен для больших сериалов. После перезапуска проверьте, что файл сохранился, запустив прослушивание/рендер без повторного выбора WAV.
10. Для MP4 используйте `CONVERT_MP4_WINDOWS.bat` и локальный FFmpeg в `tools/ffmpeg/bin` либо системном PATH. Ранее загруженный FFmpeg 9.0.2 можно использовать после распаковки.
11. Сохраните исходные голосовые и музыкальные файлы и документацию об их правах отдельно. Включение звуков в JSON **не** заменяет право на их использование в коммерческом сериале.

### Ограничения, которые намеренно не скрываем

- Хранилище браузера ограничено; **V47 не предназначена для нескольких часов несжатого WAV внутри localStorage**. Рекомендован предел 1,5 МБ на один клип. Если запись не помещается, программа сообщает об этом — используйте проектные резервные JSON и сжатое аудио. Архивный/потоковый менеджер крупных серий — задача V48.
- Микшер уже смешивает сценовые три слота V36, но нет отдельной дорожки для каждой реплики каждого персонажа, фонемной модели языка, профессионального мастеринга, экспорта stems и автоматических лицензий.
- При экспортировании полного проекта и открытии в другом браузере может потребоваться импорт JSON вручную. **Никогда не полагайтесь только на localStorage**.
- V48 — серия/сезон/MP4 и восстановление рендера, V49 UNIFIED — единый интерфейс, V50 — глубокая финальная приёмка с двумя рабочими аниме-сериями. 3D Edition только после V50.
- На старом Windows 10 8 GB RAM и GT740M начинайте с 640×360 и 6 FPS.
