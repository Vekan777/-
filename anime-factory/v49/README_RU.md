# AI Anime Factory V49 UNIFIED — единая 2D-студия

**V49 — пятая из шести фиксированных версий конечной 2D-разработки V45–V50.** В отличие от бесконечного добавления новых вкладок, V49 собирает в **один рабочий экран** существующие функциональные подсистемы:

1. **Сценарий и канон V20** — авторский сюжет, персонажи, бой, любовь, дружба, предательство и последствия.
2. **Рисовка V45** — настоящие многослойные PNG персонажей и локаций, точки привязки, источники рисунков.
3. **Анимация V46** — ключевые кадры, движения тела/рук/ног/лица, библиотека клипов, покадровая проверка.
4. **Звук V47** — переносимые небольшие WAV/MP3/OGG, громкость, движения рта по сигналу.
5. **Субтитры V37** — таймкоды, текст, SRT/VTT.
6. **Выпуск V48** — монтаж серии, титры, WebM с реальным аудио, последовательные MP4 через FFmpeg, контрольные точки завершённых серий.

Это **единая навигационная и контрольная система поверх настоящих редакторов**, не ещё один отдельный фейковый движок. Старые вкладки по-прежнему открываются для тонкого редактирования.

## Установка: Windows 10 x64

1. Загрузите `AI_ANIME_FACTORY_V49_UNIFIED_STUDIO_WINDOWS.zip` из раздела Releases проекта или основной ссылки GitHub.
2. Полностью распакуйте ZIP **в отдельную новую папку**; не заменяйте V48. Откройте `RUN_WINDOWS.bat` или `AI_Anime_Factory_V49_UNIFIED_STUDIO.html` в Chrome/Edge.
3. Откройте вкладку **«Единая студия V49»**; выберите серию. Видны общее число серий и персонажей, ошибки, замечания, шесть этапов, подробный отчёт.
4. Сразу нажмите **«Скачать ПОЛНЫЙ резерв JSON»**. Держите полученный файл на диске отдельно от ZIP. Он включает сюжет, ключевые кадры, импортированные рисунки и звук V47, а не только настройки интерфейса.
5. Перейдите по этапам в соответствующие встроенные редакторы, нарисуйте/импортируйте арт и фоны, проверьте канон, ключи движения, фонограммы и субтитры.
6. **«Я лично проверил этот этап»** отмечайте только после фактического просмотра. Отметки хранятся в `P.productionV49.reviews` отдельно по эпизоду; программа **никогда не считает это доказательством отсутствия ошибок**.
7. По каждой серии есть отчёт: где не хватает реальных PNG, отдельной анимации, встроенного звука, субтитров или сведений о правах. Список **не исчезает** от ручной отметки.
8. Сохраните режиссёрские заметки в проект, экспортируйте технический отчёт JSON и сделайте полный резервный JSON перед записью видео.
9. **«Перейти к настоящей записи серии»** открывает существующий V48 монтаж с выбранной серией; запись WebM надо запустить отдельной кнопкой в V48. MP4 и очередь серий выполняются скриптами, описанными в V48 инструкции.
10. Для переноса или восстановления выберите **«Импортировать сохранённый проект»**. Нужен ранее скачанный полный JSON. После импорта проверьте сохранность сюжета, рисунков и аудио.
11. Для многосерийного MP4 скопируйте скачанный JSON как `PROJECT_INPUT.json`, подготовьте Python, Playwright и FFmpeg и запустите `SETUP_BATCH_WINDOWS.bat`, `RUN_BATCH_WINDOWS.bat` согласно инструкции V48. Эти скрипты перенесены в V49, включая восстановление по границе проверенного эпизода.

## Что V49 действительно проверяет

Сборка проверяет сохранность оригинального V19 и V20–V48, синтаксис JavaScript, контрольную сумму архива, работу страницы в Chromium, сохранение ручных отметок по эпизодам, подготовку/экспорт полного JSON и перенос старого V48 проекта. Реальный WebM со звуком проверяется в браузере, с помощью FFprobe.

**Техническая готовность не означает художественную готовность.** Большая часть проверки качества остаётся ручной: 3D здесь нет; работа V46 является 2D-cutout анимацией, а не нарисованной с нуля плавной покадровой анимацией; V47 делает амплитудный lip-sync, не точный фонемный. Без лицензионного арта, талантливой анимационной постановки и озвучки невозможно обещать профессиональное качество сериала.

## Следующий и ПОСЛЕДНИЙ 2D-этап — V50 FINAL

V50 — **углублённый анализ багов, ручная проверка художественных сцен, сюжетной согласованности, звуков, повторная проверка Windows, итоговая инструкция «под ключ» и заключительная приёмка**. После подписанного отчёта V50 — самостоятельная 3D Edition; дальнейшие исправления существующего 2D не создают бесконечный ряд новых номеров.
