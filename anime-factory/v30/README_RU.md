# AI Anime Factory V30 — Unified Quality Review

V30 — **объединяющая контрольная версия** на базе оригинального V19 и всей сохранённой последовательности V20–V29. Ни исходный HTML V19, ни прежние модули не перезаписываются.

## Новое в V30

- Единый отчёт с уровнем ошибки/предупреждения/информации по канону V20, персонажам V23, движению V24, бою V25, камере V26, миру V27, взаимодействию V28 и анимации V29.
- Проверки структуры серий и сцен, длительности, повторных ID персонажей и отсутствующих сюжетных последствий. Используются и уже существующие проверки V20–V29.
- **Контрольная точка по явному нажатию:** фиксирует контрольные отпечатки структуры проекта, каждого персонажа, каждой серии и каждой сцены. Изменённый сюжет, настройки сцены и исчезнувшие элементы становятся заметны при последующих проверках.
- Никаких автоматических исправлений, переписывания канона, удаления серий или персонажей. Изменения фиксируются как задачи для ручного просмотра, а не блокируются.
- Скачать **полный резерв JSON**, отчёт TXT, структурный отчёт JSON с отпечатками и 4 настоящих PNG-кадра.
- Встроенный экран позволяет перейти к отмеченной серии или сцене.
- Локальный контроль внутри HTML, без отправки вашего сюжета во внешний сервис.

## Инструкция Windows 10

1. Скачайте проверенный GitHub Windows ZIP V30.
2. Распакуйте его целиком в отдельную папку.
3. Откройте `RUN_WINDOWS.bat` или `AI_Anime_Factory_V30_UNIFIED_QUALITY_REVIEW.html` в Edge/Chrome.
4. В первую очередь нажмите **«Скачать резерв JSON»**, сохраните файл в другой папке или на другом носителе.
5. Затем **«Зафиксировать контрольную точку»**. Это сохраняет эталон внутри проекта, **не заменяет резервное копирование JSON**.
6. Нажмите **«Проверить весь проект»**, выберите уровень замечаний, проверьте проблемные сцены и экспортируйте TXT/JSON отчёты.
7. Сохраните контрольный лист четырёх PNG-кадров. При необходимости исправьте отмеченные проблемы вручную и повторите проверку.
8. Для переноса из V29: экспортируйте проект JSON из V29, импортируйте в V30, сверяйте сериал/сюжет/характеры, затем создайте новый эталон.
9. Для MP4 потребуется отдельно установленный FFmpeg. Python для работы HTML не нужен. На старом ноутбуке с 8 ГБ RAM начинайте с 640×360 и 6 FPS.

## Проверки в CI

- `python anime-factory/v30/build_unified_v30.py --selftest`: гарантирует исходный V19 и присутствие всех надстроек.
- `python -m unittest discover -s tests -p 'test_*.py' -v`: Node JavaScript, интеграция, версии и статическая проверка.
- `python tests/smoke_browser_v30.py --html dist/AI_Anime_Factory_V30_UNIFIED_QUALITY_REVIEW.html`: реальный Chromium: исходный проект, эталон, резерв JSON, тестовое изменение имени сцены, обнаружение отличия, проверка сохранения канона, PNG и отчёты.
- `python scripts/build_anime_v30.py`: ZIP/CRC32/SHA256, резерв V19 и исходники.
- `python scripts/build_v7.py --legacy dist --out dist`: все исходники и прежние версии внутри объединённого V7.

## Границы результата

Контрольные отпечатки выявляют изменение данных, а не автоматически доказывают, что сюжет художественно согласован. Отчёт без ошибок **не равен** профессиональному качеству аниме или отсутствию всех смысловых противоречий. Встроенная студия всё ещё является **процедурным 2D-аниматиком**, а не настоящим 3D-движком.
