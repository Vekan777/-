# AI Anime Factory V43 — Action Camera Director

V43 добавляет **режиссуру уже существующих боевых сцен** поверх полной анимационной линии V19–V42. Это не новый сюжет и не генератор побед: V43 использует только классификацию боевых событий из канонического `v25Contact` и существующий таймлайн V35.

## Что изменилось в изображении

- Автоматический виртуальный **общий / средний / крупный план** 2D-боя, небольшое управляемое приближение и смещение центра внимания в сторону героя либо соперника.
- При настоящем попадании возможна короткая реакция камеры; при блоке и уклонении — индивидуальный ритм кадрирования. При промахе не создаётся фиктивное попадание.
- Три режиссёрских профиля: **Классическая дуэль**, **Героическая динамика**, **Общий план боя**. Отдельно настраиваются крупность, акцент на бойце, реакция, ритм и наклон.
- Переключатель **уменьшения движения** отключает тряску и наклоны камеры для более комфортного просмотра.
- Настройки привязаны к отдельному объекту `scene.directorV43`, не меняют `scene.duration`, `storyV20`, `choreographyV25`, `cameraV38` или персонажей V41.
- Вся старая графика V42, V41, V40, V39 сохраняется. Камера преобразует реальные пиксели ранее собранного кадра; субтитры V37 перерисовываются **последними**, без наклона и обрезки.
- Сохраняются предпросмотр серии, настоящий **WebM с аудио V36**, лист четырёх контрольных PNG, JSON-план камеры и аудит чрезмерной тряски.

## Установка и запуск Windows 10 64-бит

1. Скачайте `AI_ANIME_FACTORY_V43_ACTION_DIRECTOR_WINDOWS.zip` по прямой постоянной ссылке GitHub или в Releases, полностью распакуйте в **новую папку**, не поверх V35–V42.
2. Запустите `RUN_WINDOWS.bat`, либо откройте `AI_Anime_Factory_V43_ACTION_DIRECTOR.html` через Chrome/Edge. Python для запуска офлайн-редактора не нужен.
3. На вкладке «Аудит V30» сделайте полную копию проекта JSON. В том же браузере V43 попытается загрузить предыдущий локальный проект V42; при смене браузера импортируйте резерв JSON.
4. Перейдите в «**Режиссёр боя V43**». Выберите серию и именно сцену типа **Бой**. В диалогах новый кадрирующий эффект не применяется.
5. Выберите пресет (дуэль / герой / общий план), настройте крупность, акцент на участнике, реакцию, ритм и наклон. Если чувствительны к резкому движению, включите **«Уменьшение движения»**.
6. Сохраните камеру. Чтобы сравнить эффект на одном таймкоде, отключите V43, сохраните и сделайте PNG кадра; включите V43 снова и сделайте тот же кадр.
7. Просмотрите реальное изменение кадрирования на шкале всей серии. Скачайте четыре PNG, JSON режиссёрского плана и проверьте аудит комфорта.
8. Для WebM со звуком перейдите в «Звук / экспорт V36», повторно подключите свои WAV/MP3/OGG, если браузер перезапускали. Нажмите «Записать V43 с постановкой боя». Дождитесь окончания реального воспроизведения серии для загрузки WebM.
9. Для MP4 перетащите WebM на `CONVERT_MP4_WINDOWS.bat`; потребуется `ffmpeg.exe` из ранее скачанного `ffmpeg-9.0.2-full_build.zip` после распаковки, в `tools/ffmpeg/bin/` или PATH.
10. Экспортируйте итоговый полный JSON и храните свои звуковые файлы отдельно.

## Контроль качества и ограничения

В GitHub Actions запускаются Windows/Linux проверки, Node.js, настоящий Chromium, PNG-сравнение **одного кадра до/после** с доказуемым изменением пикселей, автоматический аудит сохранения исходных данных, экспорт WebM со звуком, проверка CRC32/SHA256 и объединённый V7. Старые исходники V19–V42 сохранены, а полный ZIP V42 встроен как резерв.

Это пока **2D-процедурный аниматик, а не профессиональная трёхмерная анимация или нейросетевый покадровый сериал**. Камера не улучшает форму самих моделей, но может сделать сцены боя выразительнее. На вашем Windows 10 ноутбуке с 8 ГБ RAM и GT740M начните с **640×360 / 6 FPS**.

Проверки вручную при наличии Python/Node/Playwright:

```bash
python anime-factory/v43/build_director_v43.py --selftest
python -m unittest discover -s tests -p "test_anime_v43.py" -v
python scripts/build_anime_v43.py --selftest
python anime-factory/v43/build_director_v43.py --output dist/AI_Anime_Factory_V43_ACTION_DIRECTOR.html
python tests/smoke_browser_v43.py --html dist/AI_Anime_Factory_V43_ACTION_DIRECTOR.html --out dist/V43_DIRECTOR_SAMPLES
```
