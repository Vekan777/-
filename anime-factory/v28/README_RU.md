# AI Anime Factory V28 — Character–Environment Interaction

**Фокус:** художественная убедительность процедурного 2D-аниматика. Продолжается реальная цепочка исходного V19 и слоёв V20–V27; история, канон, способности, персонажи, камера и ландшафты остаются.

## Новая постановка V28

- Положение ног и контактная пыль рассчитываются по действительному положению героя и соперника в сцене после боя V25.
- Вторичные мягкие отражения света от стилизованного окружения V27; можно отдельно регулировать интенсивность.
- Кратковременная отметка или рябь на земле при уже подтверждённом попадании либо блоке; **промах и уклонение не производят эффекта попадания**.
- Реакция мира не накапливается между кадрами и полностью воспроизводима при том же времени сцены.
- Новая вкладка «Взаимодействие V28»: следы, пыль, отражённый свет, отметины боя, световой акцент. Пресеты auto/subtle/dramatic.
- Сравнение базового кадра V27 и V28, четыре PNG и план взаимодействия TXT.
- Настройки `interactionV28` сохраняются **для каждой сцены**; прежние `storyV20`, `visualV21`, `actingV22`, `qualityV23`, `motionV24`, `choreographyV25`, `cinemaV26` и `worldV27` не удаляются.

## Установка на Windows 10

1. После успешного CI скачайте отдельный ZIP V28 из GitHub.
2. Распакуйте его полностью, затем запустите `RUN_WINDOWS.bat` или откройте `AI_Anime_Factory_V28_CHARACTER_WORLD_INTERACTION.html` в Edge/Chrome.
3. Выберите вкладку «Взаимодействие V28» → сцену → ползунки → «Сохранить взаимодействие V28».
4. Сравните кадры «до/после» и сохраните четыре PNG.
5. Создайте отдельный JSON-экспорт проекта для резервной копии.
6. При переносе из V27 предварительно выгрузите JSON старой версии и импортируйте в V28.
7. Для MP4 потребуется FFmpeg отдельно. На Windows 10 с 8 ГБ оперативной памяти начните с 640×360 / 6 FPS. Python для HTML-редактора не нужен.

## Верификация

- `python anime-factory/v28/build_interaction_v28.py --selftest`: оригинальный V19 не изменён; все интеграционные слои V20–V28 присутствуют.
- `python -m unittest discover -s tests -p "test_*.py" -v`: полный набор тестов, включая Node.js синтаксис.
- `python tests/smoke_browser_v28.py --html dist/AI_Anime_Factory_V28_CHARACTER_WORLD_INTERACTION.html`: реальный Chromium, A/B, сохранение проекта, работа ползунков, проверка несуществующего попадания и экспорт PNG.
- `python scripts/build_anime_v28.py`: SHA256, CRC32, резерв оригинального V19, исходники.
- `python scripts/build_v7.py --legacy dist --out dist`: полный комплект V7 + Anime V19–V28.

**Ограничение:** эффекты являются временными элементами 2D Canvas, а не физическими частицами, следами на постоянной карте или геометрическими 3D-деформациями. Они не модифицируют пользовательские изображения персонажей и не гарантируют качество профессионального аниме.
