# AI Anime Factory C8 Rev5 — зафиксированный результат проверки

Это продолжение C8, не C9 и **не художественно принятый профессиональный аниме-сериал**.

Реально сделано:
- Два оригинальных персонажа GLB 2.0, 14-костный скелет, 4546 треугольников, 16 **непустых** facial morph targets вместо трёх; сохранены skinning, UV, normal/baseColor/roughness PBR-карты.
- CPU WebGL/Canvas браузерный C8-предпросмотр принимает обе обновлённые GLB без JavaScript-ошибок, Face Controller управляет текстовым approximated viseme + фактическим аудиоэнергетическим envelope. Это НЕ accurate phoneme lip-sync.
- Реально импортированы и отрендерены оба GLB в Blender 3.6.23 headless/Cycles CPU, проверены shape keys, создан рендер 960×540.
- Две заново выпущенные оригинальные боевые пробы: 23,5с и 23,2с, каждая с 6 сценами; H.264 640×360 12 FPS, русская автоматическая речь / AAC. Ролики не являются эпизодами по 20–24 минуты и не имеют актёрского озвучивания.
- 22 Python-регрессионных теста и 2 JS набора (16 morph deformation и 13 skinning checks) пройдены.
- C1–C7 ZIP включены и побайтно проверены; линия V19–V50 пока не мигрирована.
- Создан **скачиваемый ZIP** `GENERATE_AND_ZIP_LOCAL_SETUP_REPORT_WINDOWS.zip` с настоящим Windows PowerShell генератором `STUDIO_TOOLS/REPORT_FOR_CHATGPT.zip`: пользователь не скачивает чужой заготовленный JSON и не обязан открывать JSON в браузере.
