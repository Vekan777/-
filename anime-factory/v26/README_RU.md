# AI Anime Factory V26 — Cinematic Combat

**Назначение:** режиссура боевых сцен в автономном HTML-редакторе с сохранением истории и исходников V19–V25. Не заменяет предыдущий сюжет, дизайн персонажей или физическую разметку событий.

## Новые возможности

- Три постановочных плана в пределах сцены: общий, средний (сближение) и акцентированная реакция в конце.
- 2D-наезд камеры, следование действию, безопасные пределы масштаба и смещения, определённые только временем сцены.
- Усиление крупного плана по уже существующим событиям V19/V17; модуль не выдумывает новые попадания.
- Кинополосы (letterbox), краткие затемнения на границах и мягкие монтажные акценты.
- Отдельные пять ползунков для боевой сцены: сила камеры, слежение, фокус, кинополосы, переходы; стили wide/dynamic/close/subtle.
- Экспорт списка планов TXT, раскадровки 4 PNG и сохранение `cinemaV26` в проектном JSON.
- Сравнение исходного кадра V25 и V26 в одной вкладке; обе стороны используют общий `drawScene` и обычный экспорт.
- Настройки V20–V25, включая `storyV20`, `visualV21`, `actingV22`, `qualityV23`, `motionV24` и `choreographyV25`, должны пережить сохранение и перезагрузку.

## Инструкция Windows 10

1. Скачайте V26 Windows ZIP по проверенной ссылке GitHub после зелёного CI.
2. Извлеките все файлы в отдельную папку.
3. Откройте `RUN_WINDOWS.bat` (или самостоятельно `AI_Anime_Factory_V26_CINEMATIC_COMBAT.html`).
4. Вкладка «Камера V26» → выберите боевую сцену → настройте стиль и ползунки → «Сохранить режиссуру V26».
5. Скачайте 4 PNG и проект JSON для резервной копии.
6. Отдельно установленный FFmpeg пригодится для MP4; в ZIP его нет.
7. Для ноутбука с 8 ГБ RAM и GT740M начинайте с 640×360, 6 FPS.

## Проверки выпуска

- `python anime-factory/v26/build_cinematic_v26.py --selftest`
- `python -m unittest discover -s tests -p "test_*.py" -v` (Linux/Windows, включая проверку Node JS).
- `python tests/smoke_browser_v26.py --html dist/AI_Anime_Factory_V26_CINEMATIC_COMBAT.html` — реальный Chromium, A/B кадры, изменения ползунков, перенос всех старых данных, PNG.
- `python scripts/build_anime_v26.py` — архив, CRC32 и SHA256 отдельных файлов; оригинал V19 в backup.
- `python scripts/build_v7.py --legacy dist --out dist` — общий пакет V7 со всеми ранее выпущенными ZIP.

## Границы результата

Выпуск делает **2D-аниматик с виртуальной Canvas-камерой**, а не профессиональное аниме с полностью нарисованными ключевыми кадрами и не 3D. Импортированные PNG и авторские изображения не изменяются. Качество конкретного эпизода требует просмотра художником/режиссёром.
