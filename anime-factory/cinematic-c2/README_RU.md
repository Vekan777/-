# AI Anime Factory — CINEMATIC C2 (рабочая версия)

C2 продолжает C1, **не меняет** исходную линию V19–V50 и сохраняет все сцены, события боя, ключи движения и медиа C1. Это функциональный автономный 2D-редактор персонажей, но **пока не генератор готовой студийной анимации**.

## Запуск Windows 10

**Самый простой способ:** скачайте [автономный HTML](https://raw.githubusercontent.com/Vekan777/-/main/anime-factory/cinematic-c2/CINEMATIC_C2_STANDALONE.html) и откройте в Chrome или Microsoft Edge. Python, Ollama и доступ в интернет для работы этого HTML не нужны. Альтернатива — скачать папку исходников, открыть `index.html` вместе с файлами `cinematic_core.js`, `character_core_c2.js`, `character_studio_c2.js`.

Выберите персонажа, правьте палитру и отличительные признаки, просматривайте 3 ракурса и 9 поз, импортируйте PNG/WebP отдельно для нужных слотов. Можно добавить до 12 собственных героев (дополнительные герои пока стоят статично). Сохраняйте полный `CINEMATIC_C2_FULL_PROJECT.json` для резервной копии, отдельно экспортируйте паспорт персонажей и PNG контакт-лист. Для звука импортируйте WAV/MP3/OGG в панель C1; браузерный TTS — только прослушивание, в WebM он не записывается. MP4 получается через FFmpeg из WebM.

## Проверки

22 группы модульных тестов C2; сохранены 16 проверок C1; 27 проверок в Chromium; записан реальный WebM с VP9+Opus; проверен импорт старого C1 JSON и отклонение повреждённой схемы C2. Отметка «проверил художественно» ставится только человеком. Генерируемые SVG — **оригинальные процедурные черновики**, не нейросетевая профессиональная рисовка; каждый финальный кадр требует художественной доработки.

**Фиксированное развитие:** C1 боевые планы → **C2 герои** → C3 риги/IK и анимация боя → C4 русский голос/SFX → C5 сюжет сезонов → C6 рендер очереди серий → **C7 UNIFIED** объединяющая без потерь → **C8 DEEP QA FINAL** углублённый аудит и художественная приёмка. Затем отдельно 3D Edition.

Для вашего ноутбука Windows 10 64-bit с 8 ГБ оперативной памяти используйте режим 640×360/12 FPS для предпросмотра. Генерация студийного качества 1080p/24 FPS полностью автоматически этим выпуском не реализована.
