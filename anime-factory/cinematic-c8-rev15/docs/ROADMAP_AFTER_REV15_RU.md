# Художественный план: C8 Rev15 → финальная C8 Studio Acceptance

Цель — НЕ новые номера версий, а проверенные преобразования исходного аниме-сериала.

| Ворота качества | Rev15 | Требования для снятия блокировки |
|---|---|---|
| Уникальные герои | Нет новых скульптов | Два отличимых полигональных скульпта, UV/PBR, детализация волос/одежды, отдельно художественная приёмка |
| Достоверный бой | Кинематическая репетиция и 3D-ключи NLA (адаптер не испытан) | Боевые акценты, опорная нога, фактический контакт оружия, перекрытия, инерция, вторичная анимация, анализ финальных 518 кадров |
| Русская речь | Реальное вызываемое выравнивание MFA, если установлено | Лицензированный голос/актёр, контроль произношения, подтверждённый TextGrid и маппинг фонем на лицевые формы |
| Искусственный режиссёр | Дет. поиск семи параметров, аудит и veto | Модель искусственного художественного критика плюс человеческие эталоны; нельзя считать пиксельный motion-score эстетикой |
| Производство серии | Отсутствует в этом архиве | Монтаж полной серии, звук, музыка по лицензии, SRT/VTT, автоматическое резюме дефектов и человеческий просмотр |
| CPU Windows | Python 3.10+ и 18 тестов | Тест под Windows 10 и Blender 3.6 на целевой видеокарте/CPU, продолжение рендера после сбоя, контроль архива и GLB |
| Объединение 2D–3D | Формат данных sidecar | Миграционные тесты по реальным файлам V19–V50, сохранение 2D сцен и сериализации историй |

Правило: кандидат исправляет конкретный измеренный дефект → независимый QA до/после → художественный просмотр → принятие только при отсутствии регрессий → сериализация контрольных сумм. Если улучшений нет, остановить цикл, предъявить блокировку и предложить изменения исходных художественных материалов, а не маскировать ошибку.
