# AI Anime Factory — C8 Rev15 Director Autopilot

**Статус: работающая экспериментальная надстройка к C8 Rev14; выпуск профессионального сериала по-прежнему `PRODUCTION_BLOCKED`.**

Это НЕ 67-МБ оригинальная Rev14 и не обновление её реальных скульптов: текущая Rev14 с `.blend`, `.glb`, моделями и видео не находится в этом архиве, поскольку исходные Rev14-бинарники предыдущего чата не доступны в данном рабочем окружении. **Ничего не удаляйте из Rev14.** Распакуйте Rev15 рядом с ней, в отдельную папку. Оригинальные сцены Rev14 не изменяются автоматически.

## Реально добавлено

1. `studio/director.py`: повторяемый перебор вариантов актёрской кинематики. Режим фиксирует события и позиции авторских ключевых точек, улучшает параметры замаха, подготовки удара, защитной руки, реакции, переноса веса, дыхания; хранит журнал всех принятых и отвергнутых кандидатов. Проверяет столкновения на уровне корневых точек персонажей, расстояния в событиях контакта (приближение, НЕ проверка столкновения самих клинков), скорости движения и долю почти неподвижных переходов в активных фазах. По умолчанию до 100 итераций, верхний предел 1000. Конец поиска по лимиту/плато. Без бесконечного цикла и без переписывания сюжета.
2. `studio/asset_gate.py`: независимый разбор `.glb`/`.gltf` на риги, morph targets, материалы, анимации, базовые PBR-карты и приблизительное число треугольников. **Структурный анализ не заменяет художественную оценку.**
3. `studio/ru_alignment.py`: при установленном MFA запускает настоящий `mfa align_one` по WAV и точной русской расшифровке. Если бинарника или модели нет, выводит `BLOCKED_NOT_ALIGNED` и не подделывает результаты.
4. `studio/textgrid_visemes.py`: проверяет интервалы фонем в TextGrid и составляет предварительную временную карту ротовых форм. Не утверждает, что риг Rev14 уже подключён к этим формам или что дикция профессиональная.
5. `studio/blender_bridge.py`: экспериментальный аддитивный слой NLA для **копии** исходного `.blend` с использованием **реальных имён костей из вашей сцены**. При несовпадении маппинга отменяет выполнение. Требуется Blender 3.6.23; *в этом окружении Blender недоступен, поэтому скрипт bpy в настоящем Blender пока не тестировался*.
6. 18 тестов Python без внешних пакетов и пример 8-секундной неканонической сцены для двух уже использовавшихся в Rev14 персонажей — Лиры и Каэла. Этот пример предназначен для проверки механики и не изменяет утверждённый сюжет.

## Быстрый запуск на Windows 10 (64-bit)

**Понадобится Python 3.10+** (в старой сборке C8 возможно уже установлен). Ссылка: https://www.python.org/downloads/windows/ . Для проверки анимации в Blender — Blender 3.6.23 с официального сайта: https://www.blender.org/download/lts/3-6/ . Для русской фонемной привязки MFA — https://montreal-forced-aligner.readthedocs.io/ . Без Blender и MFA основная кинематическая часть Rev15 работает.

1. Распаковать ZIP **в отдельную папку**, не поверх Rev14.
2. Дважды щёлкнуть `START_HERE_WINDOWS.bat`. Запустится ограниченный цикл режиссёрского поиска и появятся `output/REV15_APPROVED_MOTION.json` и `output/REV15_QA_REPORT_RU.json`.
3. Дважды щёлкнуть `RUN_QA_WINDOWS.bat` — запустятся 18 проверок.
4. Чтобы проверить свой GLB, в терминале внутри папки выполнить:
   `py -3 -m studio.asset_gate "ПУТЬ_К_ВАШЕМУ_REV14.glb" --output output/REV15_ASSET_AUDIT.json`.
5. **Не запускать экспериментальный Blender-мост на исходном файле без резервной копии.** Сначала указать настоящие имена костей в копии `examples/BLENDER_RIG_MAPPING_TEMPLATE.json`; затем:

```
"C:\PATH\TO\blender.exe" -b "C:\PATH\TO\REV14_original.blend" --python studio\blender_bridge.py -- --motion output\REV15_APPROVED_MOTION.json --mapping examples\BLENDER_RIG_MAPPING_TEMPLATE.json --out output\REV15_EXPERIMENTAL.blend
```

   При неизвестных именах костей программа **остановится**. Blender-мост не экспортирует GLB и не создаёт финальные кадры: после визуальной приёмки нужен рендер из Blender и синхронизация экспортов.
6. Для реальной фонемной привязки: установить MFA и подходящие русские модели/словари по официальной инструкции, затем:

```
py -3 -m studio.ru_alignment "voice.wav" "transcript.txt" --output output\voice.TextGrid
py -3 -m studio.textgrid_visemes output\voice.TextGrid "voice.wav" --output output\REV15_VISEMES_REVIEW.json
```

   Синхронизация **не утверждена** автоматически даже при наличии TextGrid; нужны настоящая проверка расшифровки, акустического выравнивания, мимики и артикуляции.

## Почему сериал ещё не «под ключ»

- Исходный Rev14-материал `.blend` и GLB не был импортирован в текущий ZIP. Реальных обновлённых моделей в этом выпуске нет.
- Настоящие движения рук и мечей зависят от правильной привязки костей и артистической анимации. Проверка дистанции корневых точек не гарантирует физически правильное касание клинков.
- Балл оптимизатора (`0..100`) показывает лишь близость к **явно заданной внутренней цели по семи параметрам**, а не студийное качество персонажей, анимации или зрительское восприятие. Повышение этого балла не подтверждает качество кадров.
- Для естественной русской речи нужны актёрские записи или лицензированный TTS с прослушиванием и редактурой. MFA лишь синхронизирует текст с готовым аудио.
- Для кинематографического качества необходимы уникальные студийные скульпты, UV/PBR-поверхности, работа художников над лицами, настоящие контроллеры глаз/рта, художественная постановка, финальный свет, монтаж и звуковое сведение.
- Видео, CPU-рендер, обратная совместимость с полным Rev14, реальная работа Blender-моста и установленный MFA **не проверены в этом выпуске**.
- Windows-ноутбук i7-3630QM / 8 ГБ / GT740M: начать с 640×360 Workbench/Eevee, Cycles для финальных кадров и пакетных очередей. Для полноценного 1080p 24fps может понадобиться более производительное оборудование.

## Контроль качества и миграция

Rev15 **не заменяет** C8 Rev14, C1–C7 или V19–V50. Использует самостоятельный JSON-протокол движения и явные пути к локальным Rev14 файлам. Основные исходные файлы остаются у пользователя; предыдущие сюжетные события не изменяются. Для интеграции в старый проект требуется оригинальный Rev14 `.blend`/GLB из полного архива и проверка его имён ригов.

## Творческие права

Возможен оригинальный сериал в жанре мрачного боевого фэнтези с развитием силы героя. Прямое использование персонажей, сюжетов, видео, музыки и фирменного оформления *Solo Leveling / «Поднятие уровня в одиночку»* требует надлежащих прав или лицензии. Rev15 использует только тестовые сценарные позы Лиры и Каэла.

## Политика релизов

`PRODUCTION_BLOCKED` снимается только после подтверждённой проверки рендера, актёрской пластики, лиц, реального lip-sync, целого эпизода, лицензий и ручной режиссёрской приёмки. Автоматические тесты не подменяют эти условия. Следующие изменения остаются ревизиями C8, без бесконечного переименования C9/C10.
