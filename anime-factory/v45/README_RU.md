# AI Anime Factory V45 — 2D Art & Assets + Anime Production Engine

**V45 = первый из шести оставшихся выпусков.** По принятому плану 2D завершается на **V50**: V46 анимация, V47 голос и липсинк, V48 полноценные видео-серии, V49 единая программа, V50 углублённая приёмка. Затем отдельно **3D Edition**.

## Реализовано в V45

- **Настоящие PNG-слои персонажей**: семь совместимых с исходным V15 групп (ноги, ткань, корпус, руки, лицо, волосы, оружие). Кнопка автоматически создаёт семь файлов 640×960 из встроенного векторного персонажа. Не требует от пользователя навыков рисования. Можно заменить любой слой своим PNG/WebP/JPEG.
- Каждый слой сохраняет свои смещения, масштаб и угол, **отдельную точку поворота и угол вокруг неё**. Отрисовка использует существующий `drawProductionPerson`, а не декоративные поверхностные эффекты.
- **Фон для каждой сцены:** импорт PNG/WebP/JPEG, нормализация в 1280×720, авторство, включение/выключение, настоящий рендер кадра V19/V35/V36.
- **Переносимый JSON:** PNG хранятся в самом JSON в виде data URL. Изображения можно переносить вместе с проектом без дополнительных путей; для очень больших проектов следует учитывать ограничения браузерного localStorage и использовать отдельный экспорт.
- **Anime Production Engine V45:** автономное модульное ядро на JavaScript с паспортом мира, персонажей, доступных локаций, последовательностей сцен, камер, анализа дружбы, доверия, любви, предательства и примирения; схема планирования боёв **не подменяет существующие канонические исходы V25**. Инспектор и экспорт технического JSON-плана.
- Сохранены V19–V44 целиком, включая боевые механики, звук V36/WebM, монтаж, субтитры, предыдущее движение, свет и камеры. Внутри ZIP — оригинальный V19, полный архив V44, исходники и контроль SHA256/CRC32.

## Запуск под ключ — Windows 10 64 бит

1. Скачайте `AI_ANIME_FACTORY_V45_ART_ENGINE_WINDOWS.zip` из папки `downloads/` основного репозитория либо GitHub Releases. **Распакуйте в отдельную новую папку**, не заменяйте V44.
2. Запустите `RUN_WINDOWS.bat` или `AI_Anime_Factory_V45_ART_ENGINE.html` в Chrome/Edge.
3. Если у вас уже есть свой проект, **сначала экспортируйте резервный JSON**. Редактор V45 подхватит сохранённый V44 из того же браузера, если такой есть. При переходе между ПК импортируйте ваш JSON.
4. Вкладка **«2D Арт и движок V45»**: выберите героя и нажмите «Создать 7 прозрачных PNG из встроенного рига». Изображения сразу участвуют в рендере сцен; выберите сцену и посмотрите предпросмотр.
5. Замените отдельные слои своими PNG/WebP/JPEG, если они есть. **Не обязательно** рисовать всё вручную: встроенная векторная основа остаётся запасным вариантом. Изображения нормализуются в сетку 640×960.
6. По желанию настройте смещения, масштаб, угол и **точку поворота** каждого слоя. После каждого изменения нажмите «Сохранить слой и точку поворота».
7. Для мира выберите сцену в редакторе, откройте V45 и загрузите её фон. Добавьте права на изображение, сохраните.
8. Скачайте **ПОЛНЫЙ JSON с изображениями**, четыре реальных PNG-кадра и инженерный паспорт сериалов/отношений/локаций.
9. Для видео перейдите в прежнюю вкладку «Звук / экспорт V36» — там работает запись WebM с подключёнными WAV/MP3/OGG. Для MP4 после записи используйте `CONVERT_MP4_WINDOWS.bat` с FFmpeg 9.0.2 (в `tools/ffmpeg/bin` либо PATH).
10. Сделайте дополнительную резервную копию после редактирования и сохраните также файлы исходных рисунков и звук. **V47 ещё предстоит сделать аудио полностью переносимым в проекте**.

## Отношения и зрелые сюжетные сцены

Движок включает структурные линии дружбы, доверия, романтической близости, предательства и примирения. Он может хранить авторскую постановку приватной сцены, эмоции, согласие и ракурсы на уровне сценария. **Не заявляется**, что V45 сам создаёт профессиональный покадровый романтический эпизод или любые желаемые изображения без художественных материалов.

## Почему это пока не «студия как у профессионалов»

V45 действительно импортирует/создаёт слои и связывает их с рендером. Но **не умеет автоматически разрезать произвольную плоскую PNG-картинку на семь анатомически корректных частей**; многослойность требует соответствующего исходного арта. Полноценные ключи/деформации V46, фонемный липсинк V47, сезонный рендер V48 и единый интерфейс V49 ещё впереди. Тесты подтверждают работу ПО, **но не гарантируют качество художественного рисунка**.

Для ноутбука Core i7-3630QM, 8 ГБ RAM и GeForce GT740M рекомендуется начать с 640×360, 6 FPS. Более подробный план: `anime-factory/roadmap/2D_FINAL_TO_V50_RU.md`.
