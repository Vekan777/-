# AI Anime Factory V27 — World & Environment Quality

**Новая версия** расширяет 2D-аниматик, последовательно сохраняя подлинный V19 и разработанные надстройки V20–V26. Улучшается художественное окружение кадров, а не инфраструктура.

## Возможности V27

- Многослойное процедурное окружение с разной скоростью фоновых деталей, перспективной сеткой и дымкой.
- Выбор типа фона: город, лес, храм, поле боя либо автоматическое сохранение типа из сценария.
- Контактная тень и световые пятна под **реальным положением каждого персонажа**, в том числе после корректировки боя V25.
- Управление глубиной, освещением, контактом с землёй, воздушной перспективой и передним планом.
- Рисование фона **до** персонажей, контактных теней **под** персонажами, ограниченных краевых силуэтов **после** переднего плана камеры. Это работает и в основной экспортной функции `drawScene`.
- A/B кадр одинакового времени в V26 и V27; 4 PNG-кадра и паспорт окружения TXT.
- Отдельный объект `worldV27` для каждой сцены, сохраняемый в JSON, без удаления `storyV20`, `visualV21`, `actingV22`, `qualityV23`, `motionV24`, `choreographyV25`, `cinemaV26`.

## Как запустить на Windows 10

1. Скачайте проверенный Windows ZIP V27 из GitHub после успешного завершения CI.
2. Распакуйте все файлы в отдельную папку; откройте `RUN_WINDOWS.bat` или `AI_Anime_Factory_V27_WORLD_QUALITY.html` через Chrome/Edge.
3. Вкладка **«Мир V27»** → сцена → ландшафт → ползунки → «Сохранить окружение V27».
4. Скачайте 4 PNG и экспортируйте JSON проекта для резервного копирования. Исходный V19 находится в папке `backup/`.
5. В случае переноса V26 сначала экспортируйте JSON из старого редактора, затем импортируйте его в V27 и сравните серии/героев.
6. Для MP4 потребуется отдельный FFmpeg. На ноутбуке с 8 ГБ RAM начните с 640×360, 6 FPS. Python для самого HTML редактора не нужен.

## Автоматизированная проверка

- `python anime-factory/v27/build_world_v27.py --selftest`: интеграция без изменения V19.
- `python -m unittest discover -s tests -p "test_*.py" -v`: Python, Node.js, миграция и старые версии (Windows/Linux).
- `python tests/smoke_browser_v27.py --html dist/AI_Anime_Factory_V27_WORLD_QUALITY.html`: реальный Chromium, PNG-сравнение, регулировка фона, сохранение и восстановление JSON V20–V27.
- `python scripts/build_anime_v27.py`: автономный Windows ZIP, резерв V19, SHA-256 и CRC32.
- `python scripts/build_v7.py --legacy dist --out dist`: общая V7 с прежними архивами и V27.

**Ограничения:** этот выпуск обеспечивает стилизованную глубину и атмосферу в **2D Canvas**, но не настоящий геометрический 3D-мир. Он не заменяет профессиональные нарисованные фоны, motion capture или покадровую анимацию; загруженные PNG персонажей сохраняются без модификации.
