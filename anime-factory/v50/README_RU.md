# AI Anime Factory V50 FINAL — завершение согласованного 2D-плана

**V50 — последняя из шести фиксированных версий V45–V50.** Включает всю предыдущую функциональность, объединённую в V49, и отдельную углублённую проверку, но **не заявляет**, что процедурные рисунки стали профессиональным аниме без участия художников.

## Что работает в финальной сборке

- Оригинальная история V19 и все дополнения V20–V49; V20 фиксирует сюжет, травмы, потери памяти, дружбу, доверие, предательство, любовь и последствия действий.
- Действующие 2D-cutout персонажи и рисунки локаций V45, позы и библиотека клипов V46, короткие WAV/MP3/OGG внутри полного JSON V47, озвученный WebM и экспорт двух+ эпизодов в H.264/AAC MP4 V48 через Playwright/FFmpeg, шесть рабочих этапов единой студии V49.
- **Новая вкладка «ФИНАЛЬНАЯ QA V50»**: сводный аудит по всем сериям, счётчики ошибок и замечаний, проверка названий сцен, последствий сюжета и состояния героя, дублирующихся ID персонажей, файлов арта и голосовых data URL, семи слоёв рига, прав, повреждённых анимационных ключей, некорректных уровней громкости, времени голосовой дорожки и субтитров, неверной продолжительности.
- **Сохранение индивидуальной ручной приёмки** каждой серии: отдельно сюжет, персонажи/арт/лицензии, движения/бои, звук, субтитры, выпуск видео и художественный просмотр.
- **Полный резерв JSON** плюс отдельный машинный отчёт QA; импортер совместим с JSON предыдущих версий, если они корректны. Отчёт никогда не объявляет художественный результат «профессиональным» только по структурным тестам.
- Исходники и архив V49 входят в V50, контрольные суммы SHA256 и ZIP CRC32; отдельная объединённая сборка V7 содержит всю историю исходных редакторов.

## Установка и запуск Windows 10 x64 (под ключ)

1. Скачайте `AI_ANIME_FACTORY_V50_FINAL_2D_WINDOWS.zip` с постоянной ссылки GitHub Releases или из `downloads/`. Распакуйте **целиком в НОВУЮ папку**, не заменяя V49.
2. Дважды щёлкните `RUN_WINDOWS.bat` — откроется `AI_Anime_Factory_V50_FINAL_2D.html` в Chrome/Edge. Для одиночного редактирования Python не требуется.
3. Если проект уже сохранён в предыдущей версии, откройте V50 в том же браузере либо нажмите «**Восстановить полный проект из JSON**» и импортируйте свой файл. **Сразу экспортируйте новую резервную копию.**
4. Вкладка **«Единая студия V49»** открывает реальные шесть этапов: сценарий, арт, анимация, голос, субтитры, монтаж. Там выполните необходимые исправления, не удаляя исторический сюжет.
5. Вкладка **«ФИНАЛЬНАЯ QA V50»** → выберите серию → прочитайте все ошибки и замечания. Заявленные критические ошибки исправьте в том редакторе, где возникла проблема, **не редактируйте JSON вручную без резервной копии**.
6. Просмотрите сцену за сценой художественно: персонажи должны иметь настоящий выразительный арт, движения не должны «перескакивать», глаза и лицо должны быть читаемы, сюжетные последствия согласованы, голос и музыка без обрыва, титры и субтитры в верное время.
7. **Только после фактической проверки** отмечайте каждую из семи галочек ручной приёмки. Программа не скрывает нерешённые ошибки независимо от этих отметок. Запишите замечания в проект.
8. **Перед экспортом** скачайте «ВЕСЬ проект JSON», содержащий сюжет, многослойные изображения, движения V46 и звуки V47. Также скачайте отчёт `V50_FINAL_DEEP_QA_REPORT.json`.
9. Перейдите «Открыть настоящий рендер V48» и выпустите один WebM. Прослушайте и посмотрите его в обычном видеоплеере, а затем проверьте SRT/VTT и титры. Файл WebM должен содержать реальные видеопакеты и звуковую дорожку.
10. Для **автоматического выпуска нескольких серий и MP4** сохраните JSON под именем `PROJECT_INPUT.json` рядом с `RUN_BATCH_WINDOWS.bat`. Установите Python 3.11+ x64 (<https://www.python.org/downloads/windows/>), запустите `SETUP_BATCH_WINDOWS.bat` с интернетом для Playwright Chromium, распакуйте имеющийся FFmpeg 9.0.2 так, чтобы `ffmpeg.exe` и `ffprobe.exe` оказались в `tools\ffmpeg\bin\`, затем запустите `RUN_BATCH_WINDOWS.bat`. Исходный скрипт V48 включён в V50. Результаты в `OUTPUT\`: WebM, H.264/AAC MP4, SRT, VTT, отчёт и SHA256-чекпоинт.
11. Если обработка остановилась, снова запустите `RUN_BATCH_WINDOWS.bat`. Готовые эпизоды пропускаются, если совпадают контрольные суммы проекта, HTML, FPS и настоящего видео. **С середины эпизода возобновления нет**.
12. После записи откройте **каждую** серию, а не только технический отчёт, проверьте звук и графику, убедитесь в правах на исходные изображения, музыку и голоса. Только после этого считайте свою работу готовой к публикации.

## Программы и возможности компьютера

- Редактор: Windows 10 x64, Chrome/Edge. Работает локально HTML/Canvas 2D без серверного API.
- Автосборка нескольких серий: Python 3.11+, Playwright 1.56.0 и Chromium, FFmpeg/FFprobe. Требуется свободное место для исходных арт-/аудиофайлов и итогового видео.
- Для слабого ноутбука i7-3630QM / 8 GB RAM / GT740M разумно начать с **640×360, 6 FPS, одной короткой сцены**. Полноценная студийная анимация 1080p/24 FPS на таком устройстве не гарантирована.
- В архиве есть RUN_WINDOWS.bat, SETUP_BATCH_WINDOWS.bat и RUN_BATCH_WINDOWS.bat, а также русские инструкции.
- Монетизация требует собственных или лицензированных рисунков, музыки и голосов. Встроенные проверки текста `rights` **не подтверждают юридические права**.

## Честные ограничения

Сборка **готова для проверки и производства процедурных 2D-cutout эпизодов**, однако она не может автоматически создавать студийную покадровую рисовку, безупречные эмоции и кинематографию в качестве коммерческого сериала без художественной работы. Система V47 — амплитудный lip-sync, а не настоящий фонемный разбор. Звуковые клипы ограничены квотой локального хранилища; несколько часов записей в одном JSON не рекомендуются.

**Приёмка V50 делится на две части.** CI подтверждает структуру, сохранность исторического кода, экспорт и техническую целостность реальных тестовых файлов. **Художественная приёмка** — проверка персонажей, игры, эмоций, монтажа, качества голоса, прав и итоговых серий — остаётся за владельцем проекта. Пока она не проведена, нельзя утверждать, что профессиональный 2D-сериал закончен и можно безопасно начать 3D.

Если требуется создавать персонажей и фоны автоматически через полноценные нейросетевые модели, понадобится отдельно подключить генерацию медиа и подходящее аппаратное обеспечение; V50 не включает скачивание гигабайтных моделей и не гарантирует такое качество автономно.
