# AI Anime Factory V25 — Combat Choreography

V25 расширяет реально сохранённую в GitHub цепочку V19 → V20 → V21 → V22 → V23 → V24. Это отдельное улучшение **постановки двух бойцов**, а не новый 3D-движок.

## Что изменено

- Согласованное положение и расстояние между двумя актёрами на каждом кадре.
- Движения рук в нападении и защите, рывок атакующего, отдача защищающегося, отступление при уклонении.
- Отличие промаха, блока, попадания и уклонения — **только на основании уже назначенных событий V19/V17**, не на основании картинки или случайного эффекта.
- Новый раздел «Хореография V25» с настройками: дистанция, перемещение, защитная стойка, реакция и ритм. Отдельные значения сохраняются в `choreographyV25` каждой сцены.
- Сравнение одного и того же момента сцены до/после V25; четырёхкадровый контактный PNG и текстовый план дуэли.
- Генерация финального HTML из оригинального V19 и надстроек V20–V25 без перезаписи прежних исходников.
- Прежние история, серии, канон, способности, эмоции, свет, костюмы и анимация доступны в тех же вкладках. Проекты V24 можно перенести через JSON.

## Windows 10 — запуск без Python

1. Скачать проверенный V25 Windows ZIP после прохождения GitHub Actions.
2. Распаковать целиком в новую папку; запустить `RUN_WINDOWS.bat` либо открыть HTML напрямую в Chrome/Edge.
3. Выбрать «Хореография V25», боевую сцену, настроить расстояние, движения и защиту.
4. Нажать «Сохранить V25». Экспортировать JSON проекта и четыре PNG кадра.
5. Для MP4 использовать FFmpeg, который не входит в ZIP. На ноутбуке с 8 ГБ RAM начать с 640×360, 6 FPS.

## Проверки

- `python anime-factory/v25/build_combat_v25.py --selftest`: сохранность V19 и присутствие модулей V20–V25.
- `python -m unittest discover -s tests -p "test_*.py" -v`: проверка Python и JS на Windows и Linux.
- `python tests/smoke_browser_v25.py --html dist/AI_Anime_Factory_V25_COMBAT_CHOREOGRAPHY.html`: реальный Chromium, сравнение A/B, сохранение и перезагрузка данных, экспорт PNG.
- `python scripts/build_anime_v25.py`: ZIP, CRC32, SHA-256 каждого файла и резерв V19.
- `python scripts/build_v7.py --legacy dist --out dist`: общий V7 с архивами прежних версий и новым V25.

**Ограничения.** Это 2D-аниматик. Движения условные, а не физическая симуляция со скелетными IK, захватом движения, автоматическим созданием профессиональных художественных кадров или доказанным столкновением оружия. Пользовательские изображения PNG не перерисовываются. Проверки GitHub показывают техническую работоспособность, но не художественное качество на конкретном ноутбуке.
