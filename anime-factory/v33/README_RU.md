# AI Anime Factory V33 — Character Acting & Expression

V33 продолжает подлинный HTML-редактор V19 и сохраняет полный набор обновлений V20–V32.

## Что изменено

- Направленный взгляд (включая медленные движения зрачка) и усиление эмоций **глаз, бровей и выражения лица**. Результат опирается на V22 настроение сцены и V32 ключевые позы.
- Актёрские жесты: небольшие согласованные движения кистей, локтей, головы и корпуса, плюс спокойный дыхательный ритм. Переходы вычисляются от текущего времени сцены без случайных значений.
- Выбор стиля «Кинематографично», «Выразительно», «Сдержанно». Пять настроек: взгляд, эмоция, жест, дыхание, переходы.
- Настройки сохраняются **отдельно для каждой сцены** в поле `actingV33` проекта. Импорт, сюжет, канон, персонажи, V30-контрольная точка и параметры V31/V32 сохраняются.
- **Настоящее сравнение Canvas V32/V33** при одинаковом времени, четыре PNG и текстовый план актёрских сигналов для каждой сцены.
- Модуль меняет **геометрию и мимику реального процедурного 2D-рига**, а не накладывает поверх кадра декоративный фильтр.
- **Загруженные PNG/портреты пользователя не перерисовываются**. Для них изменения лица и кистей могут быть незаметны; переходы штатных сюжетных треков остаются прежними.
- Система V19/V17 решает, попал ли удар. V33 не меняет результат боя и не создаёт новые события сюжета.

## Подробный запуск на Windows 10

1. Скачайте опубликованный Windows ZIP V33, проверьте окончание имени на `ACTING_EXPRESSION_WINDOWS.zip`.
2. Полностью распакуйте в отдельную папку Windows 10 x64. Не запускайте BAT внутри архива.
3. Откройте `RUN_WINDOWS.bat` или `AI_Anime_Factory_V33_ACTING_EXPRESSION.html` в Chrome/Edge.
4. Сначала скачайте **полную резервную копию JSON** через основную кнопку или старую вкладку «Аудит V30».
5. На вкладке «Актёрская игра V33» выберите сцену, задайте взгляд, силу эмоции, жест, дыхание и плавность. Можно нажать «Профиль выразительной игры».
6. Передвиньте ползунок времени и сравните одинаковые кадры V32 и V33. Нажмите «Сохранить актёрскую игру».
7. Скачайте четыре PNG и TXT-план, проверьте несколько ключевых моментов сцены.
8. Для миграции из V32 экспортируйте JSON в старой программе и импортируйте в V33; проверьте героев и сюжет.
9. Python для самостоятельного HTML-редактора не нужен. Для MP4 нужен установленный отдельно FFmpeg. На 8 ГБ RAM используйте сначала 640×360, 6 FPS.

## Проверки

- `python anime-factory/v33/build_acting_v33.py --selftest`: исходный V19 неизменён, есть функции V19–V33.
- `python -m unittest discover -s tests -p "test_*.py" -v`: включая тесты Python/Node Windows и Linux.
- `python tests/smoke_browser_v33.py --html dist/AI_Anime_Factory_V33_ACTING_EXPRESSION.html`: реальные кадры V32 против V33, изменение жестов и мимики, экспорт PNG/TXT и сохранение JSON после перезагрузки.
- `python scripts/build_anime_v33.py`: отдельный Windows ZIP с резервом V19, исходниками и проверкой CRC32/SHA-256.
- `python scripts/build_v7.py --legacy dist --out dist`: общий архив V7 со всеми прежними редакциями.

## Ограничения

V33 остаётся **процедурным 2D-аниматиком**, а не полноценным студийным сериалом, 3D-движком или нейросетевым генератором персонажей. Эмоции опираются на ранее заданное сценическое настроение, а не глубокое понимание актёрского подтекста. Браузерный тест подтверждает реальные изменения пикселей и сохранение данных, но не гарантирует художественную привлекательность каждого персонажа.
