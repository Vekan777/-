# AI Anime Factory V46 — Animation Engine

V46 — **второй выпуск из шести**, предусмотренных конечным 2D-планом V45–V50. Эта версия не добавляет очередной декоративный режим: новая анимация работает в самом `pose16Sample`, по которому реальные части 2D-персонажа V45 поворачиваются в кадрах и в итоговом WebM.

## Что реально добавлено

- Настоящий редактируемый таймлайн по **семи слоям персонажа**: ноги, ткань, корпус, руки, голова/лицо, волосы, оружие. Отдельные треки для главного героя и второго персонажа.
- Запись, обновление, удаление ключей по точному времени; смещение X/Y, поворот, масштаб; **smooth / linear / hold** переходы.
- Пресеты из **35 ключевых кадров каждый**: ходьба, защита, взмах, поклон, тёплый/дружеский жест. Пресеты делают реальные движения частей уже существующих рисованных слоёв, но не переписывают исходы боя и отношения.
- **Библиотека клипов** на уровне сериала `P.animationClipsV46`: сохранили движение в одном эпизоде, выбрали следующую сцену, применили к одному персонажу без потери остальных слоёв.
- Покадровый просмотр, воспроизведение во времени и **onion skin**: соседние реальные кадры полупрозрачно поверх текущего изображения.
- Экспорт PNG-листа четырёх кадров, JSON-плана анимации и всей серии через имеющийся V36 MediaRecorder со звуком.
- Сохранение новых ключей в отдельном `scene.animationV46`, чтение старых V16-поз как исходной базы, оригинальный V19 и полная функциональность V20–V45.
- Детерминированная интерполяция — один таймкод даёт те же геометрические позы.

## Запуск Windows 10 x64

1. Скачайте `AI_ANIME_FACTORY_V46_ANIMATION_ENGINE_WINDOWS.zip` из постоянной папки GitHub `downloads/` или Releases после публикации. **Полностью распакуйте** в отдельную папку, не поверх V45.
2. Дважды щёлкните `RUN_WINDOWS.bat`, либо откройте `AI_Anime_Factory_V46_ANIMATION_ENGINE.html` в Chrome/Edge. Python и Node не требуются для просмотра в браузере.
3. **Сразу сделайте резерв** полного JSON на вкладке «Выпуск/QA». V46 подхватывает локальный сохранённый проект V45 из того же браузера; при переносе компьютера импортируйте JSON.
4. Во вкладке **«2D Анимация V46»** выберите эпизод, сцену, участника и часть тела. Для героя с собственными арт-слоями сначала подключите их в «2D Арт и движок V45».
5. Выберите один из пяти готовых движений, нажмите «Создать 35 настоящих ключей». Поэкспериментируйте с ходьбой, защитой, взмахом, поклоном и тёплым жестом.
6. Чтобы править конкретный момент, переместите **таймкод**, выберите слой тела, измените X/Y/угол/масштаб и нажмите «Записать/обновить ключ». Переключите способ перехода (плавно/линейно/удержание) и сравните настоящие кадры.
7. Включите **onion skin**, чтобы видеть полупрозрачные соседние кадры. Кнопка «Четыре подлинные позы PNG» сохраняет лист контроля движения.
8. Назовите клип, нажмите «Сохранить движения в библиотеку», перейдите в другую сцену, выберите клип и «Применить». Ключи перенесутся на выбранного персонажа.
9. Скачайте JSON-план анимаций и **полный JSON проекта** для переноса арт-слоёв и сохранённых клипов.
10. Записывайте WebM со звуком через вкладку V36 с вашими WAV/MP3/OGG. Для MP4 запустите `CONVERT_MP4_WINDOWS.bat` с установленным FFmpeg в `tools/ffmpeg/bin/` либо PATH.
11. Храните резервные JSON, рисунки и аудио отдельно. **V47** устранит ограничение V36 на встроенное переносимое аудио; до V47 звук может требовать повторного выбора после перезапуска.

## Что остаётся до 2D FINAL

- **V47**: переносимая озвучка, микшер, синхронизация губ с речью.
- **V48**: пакетный рендер целых серий, MP4 и восстановление после прерывания.
- **V49 UNIFIED**: единый удобный интерфейс и завершённая демонстрационная серия.
- **V50 FINAL**: глубокая проверка сценария, исходников, видео, звука, художественных сцен, Windows и всей цепочки «под ключ».
- 3D Edition — **отдельный проект после полного завершения V50**, не продолжение бесконечной цепочки 2D номеров.

Границы: V46 — полноценная **редактируемая 2D-cutout анимация** частей тела, но не профессиональная деформация mesh/Spine, не автоматическое извлечение скелета из одной фотографии и не гарантия профессионального художественного качества. Бой, дружба, предательство, романтические и приватные сцены могут быть написаны, поставлены и анимированы, но не возникают без авторской постановки. Для слабого ноутбука Windows 10 8 ГБ RAM/GT740M начните с **640×360 при 6 FPS**.
