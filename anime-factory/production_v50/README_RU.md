# AI Anime Factory V50 — производственный пилот 2D (не V51)

Дата запуска: 21 октября 2026. Ветка `anime-v50-production-pilot-2d`.
Это **дополнение к опубликованной V50**, не новая главная версия, не замена
канона и не заявление о готовом профессиональном сериале. Оригинальные исходники
V19–V50 и опубликованные ZIP V48/V49/V50 не переписываются.

## Созданные сюжетные серии

- **01 — «Сигнал Разлома»**. В пепельном городе Акира обнаруживает первый сигнал.
  Рэн спасает друга, но прячет символ тайной сделки. Призыв хранителя защищает
  Мию и стирает у Акиры память о родном доме. Мию начинает дневник воспоминаний.
  Драматическая цель: зритель должен сопереживать ЦЕНЕ спасения, а не только ударам.
- **02 — «Старый друг»**. Рана Акиры не исчезает. Рэн рискует собой, спасая
  его, но скрывает угрозу сестре. В зеркальном храме Акира вновь использует
  запретную силу и забывает первую встречу с Мию. Печать ведёт к Совету.
  Драматическая цель: усилить привязанность к героям и тревогу вокруг Рэна.

У каждой серии шесть сцен (завязка, дружба, бой, близость, мотив
предательства, последствие), 12 прописанных реплик, планы камеры, актёрская
задача и отдельные субтитры. Никакого внезапного признания Рэна в первой серии
нет: его окончательное предательство остаётся в более поздней арке сезона.

## Фактический результат этой ветки

Скрипт `scripts/produce_2d_pilot_v50.py` читает настоящий базовый проект
через собранный V50 Chromium, **делает рабочую копию** и дополняет первые
две серии, оставляя все остальные серии, структуру боя и исторические
версии на месте. Он умеет приложить русскую временную озвучку eSpeak NG
в переносимом MP3 и построить V47 огибающую губ. Полный проект выгружается
в `PROJECT_PILOT_V50.json`. Голоса пока роботизированные и являются
черновыми; никакого одобрения коммерческих прав или художественного
качества код не выставляет.

В GitHub Actions отдельный процесс должен:
1. Создать V50 HTML из исторических исходников без их модификации.
2. Создать полный JSON с репликами, MP3, титрами и V50 QA.
3. Записать по 12 **реальных PNG-кадров** для независимого просмотра.
4. В реальном времени записать две **полные** пилотные серии без
   `--qa-short` и конвертировать WebM → MP4 H.264/AAC.
5. Запустить FFprobe, проверить длительность, аудиодорожки, слышимый звук,
   повторный запуск рендера без повторного экспорта готовых серий.
6. Выложить **GitHub Actions Artifacts** (НЕ Releases). Артефакты
   временные: необходимо скачать и хранить свои копии.

До зелёного завершения workflow этот результат — **подготовленная
автоматизация**, а не заявленные готовые MP4. Даже успешный workflow
**не означает**, что кадры красивы или готовы к платной публикации.

## Проверка художественного качества — обязательно для каждой серии

Просмотр **кадр за кадром и со звуком**, минимум на большом экране:
- Лицо и силуэт персонажей различимы без текста; пропорции и одежда стабильны.
- Акира явно бережёт травмированное плечо; зритель видит плату за вызов души.
- Отношения Акиры и Мию развиваются поступками, а не «телепортацией эмоций».
- Рэн скрывает символ, но предательство не раскрывается раньше канона.
- Бой: направление ударов, контакт, география, реакция и исход непротиворечивы.
- Фоны не похожи на повторяющийся шаблон; планы не статичны весь эпизод.
- Рот не «говорит» во время чужой реплики; речь читаема и совпадает с субтитрами.
- Реплики не обрезаны сценой, музыка не заглушает речь; нет длинной мёртвой тишины.
- Есть смена общего, среднего и крупного планов с понятной логикой.
- Читаемость текста на 640×360; субтитры не закрывают лицо.
- Никаких лишних логотипов/водяных знаков, лицензии подтверждены документально.
- Полностью просмотрен финальный MP4, не только четыре PNG и отчёт тестов.

**Ожидаемые недостатки чернового пилота:** встроенные процедурные cutout
персонажи могут быть недостаточно выразительными; TTS не передаёт актёрских
эмоций; lip-sync амплитудный и не может надёжно менять говорящего в пределах
одной сцены; музыка и эффектные шумы пока не сведены; художественные права
на сторонние материалы не проверены. Эти недостатки должны быть исправлены
и утверждены людьми. Нельзя проставлять «принято» автоматически.

## Сколько ещё этапов до перехода в 3D

**Не нужны новые основные 2D-версии.** V49 остаётся объединяющей,
V50 — технической финальной базой. Два конечных исправительных этапа:

- `V50.1 PRODUCTION`: реальные серии 01–02, замена временной речи
  качественным озвучиванием, фоны/мимика/анимация, план сезона.
- `V50.2 ACCEPTANCE`: художественная коррекция всех производимых серий,
  комплексный выпуск, тест Windows 10 на маломощном ПК, полная проверка прав,
  отчёт и повторная сборка **V50 UNIFIED FINAL 2D**.

Переход к `3D Edition v1` допускается только после фактической приёмки
завершённых эпизодов. На сегодня автоматический релиз V50 технический, а не
художественный. Никакие флаги в историческом `2d_completion_contract.json`
не переключаются без проверенных доказательств.

## Запуск в GitHub

Откройте pull request этой ветки → вкладка **Checks** → workflow
`V50 2D pilot episodes and artistic evidence (non-final)`.
После успешного запуска откройте **Actions** → соответствующий запуск →
**Artifacts**:

- `V50_2D_PILOT_REVIEW_FRAMES_AND_PROJECT` — JSON, QA, 12 кадров.
- `V50_2D_PILOT_TWO_REAL_MP4_WEBM` — две серии, MP4/WebM, SRT/VTT,
  контрольные суммы и отчёты.

Затем загрузите `PROJECT_PILOT_V50.json` в опубликованный редактор V50
через «Восстановить полный проект из JSON». Для выпуска на ПК уже имеется
FFmpeg 9.0.2: распакуйте `ffmpeg.exe`/`ffprobe.exe` по инструкции V50,
отдельный повторный архив FFmpeg не нужен.

## Для разработчика (Linux runner / Windows вручную)

```sh
python anime-factory/v50/build_final_v50.py --output dist/AI_Anime_Factory_V50_FINAL_2D.html
python -m pip install playwright==1.56.0
python -m playwright install chromium
python scripts/produce_2d_pilot_v50.py --validate-only
# Для пробной русской озвучки дополнительно установить espeak-ng и FFmpeg:
python scripts/produce_2d_pilot_v50.py --tts
python tests/smoke_pilot_v50.py --html dist/AI_Anime_Factory_V50_FINAL_2D.html --project dist/V50_PILOT_2D/PROJECT_PILOT_V50.json --out dist/V50_PILOT_2D/REVIEW_FRAMES
python scripts/render_anime_v48.py --html dist/AI_Anime_Factory_V50_FINAL_2D.html --project dist/V50_PILOT_2D/PROJECT_PILOT_V50.json --out dist/V50_PILOT_2D/VIDEO --episodes 1,2 --fps 6 --mp4
```

Для слабого ноутбука Core i7-3630QM / 8 ГБ / GT740M начинайте
с 640×360 и 6 FPS. Технически корректное HD-изображение и профессиональная
анимация — разные критерии. Не удаляйте ваши прежние ZIP или полные JSON
сохранения.
