# Реальные ZIP в GitHub

Все архивы ниже реально загружены и видны через GitHub Contents API.
Они созданы экстренным резервным ZIP-сборщиком (STORE, CRC32).
Полноценные Python/Windows-тесты ещё не пройдены: GitHub Actions остаётся в очереди.
НЕ путайте эту реконструкцию с прежними архивами, которые скачивались кнопками внутри ChatGPT.

Для Android нажмите на ссылку и скачайте ZIP. Для Windows ZIP сначала распакуйте.
Установите Python 3.10+, затем дважды щёлкните RUN_WINDOWS.bat в отдельном V1–V6 ZIP.
Исходники можно просмотреть в корне репозитория.

Оригинальные бинарные ZIP/MP4 аниме V19 по-прежнему лежат в библиотеке ChatGPT;
они не заменяются вновь собранными ZIP и НЕ перенесены сюда.
