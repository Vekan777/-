## Реальные новые возможности
- `engine/visual_autofix.py`, команда `design-safe-fix` в factory.py и кнопка «6 · Безопасная CSS-правка» в существующей Studio;
- только после `confirmed_by_owner:true` в файле JSON с координатами, только на сгенерированном черновике, только селекторы `.hero-copy`, `.hero-art`, `.section-copy`, до трех блоков на устройство;
- адаптивные media rules для ПК и телефона, одно смещение ±24 px; просмотр без записи по умолчанию, отдельное `--apply` с подтверждением;
- обязательный браузерный QA до и после, геометрическая повторная проверка, HTML QA, проверка горизонтальной прокрутки, ошибок JS и битых изображений. При `--desktop` / `--mobile` дополнительно проверяется изменение технической растровой метрики относительно настоящего эталона; ухудшение более 0,25 п.п. вызывает откат;
- original CSS сохраняется вне сайта, недоказанное изменение автоматически откатывается байт в байт; второй автоматический проход до ручной приемки запрещен;
- отдельные JSON отчеты, Windows BAT, 9 новых регрессионных тестов.

## Доказательства
Из чистой распаковки: старые тесты `99 passed, 1 skipped`, новые `9 passed` (в отдельных запусках); всего 108 успешно, 1 пропущен. CLI dry run `PROPOSED_NOT_APPLIED`, apply `ACCEPTED_GEOMETRY_IMPROVEMENT`. На синтетических размеченных макетах суммарное абсолютное отклонение двух блоков 51 → 0 px. Контрпример: геометрия 51 → 0 px, но растровое сходство уменьшилось на 2,45 процентного пункта, поэтому `ROLLED_BACK_NO_IMPROVEMENT` и исходный CSS восстановлен. Demo preview ZIP проверены. Linux Python/Tkinter doctor core_ready=true; Windows GUI пользователя не проверен.
