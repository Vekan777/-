# Solo VPN V46 — передача проекта, 24 октября 2026

**Важное:** полные исходники находятся в ZIP `SOLO_VPN_V46_FULL_PROJECT.zip`, созданном в данном диалоге, НЕ в GitHub. Ветка `solo-vpn-v8-build` содержит исторические материалы и памятки; при V47 не подменять ими полный V46.

V46 создана поверх полного пользовательского ZIP V45. Сохраняются 11 страниц сайта, чёрно-фиолетовый аниме-дизайн и теневой охотник, четыре утверждённых макета, Android и API, Jinja2/Tkinter Studio, инструменты и старые версии. Исправлен скрытый мобильный дефект склеивания текста «мире.Защищай».

Обновления: самостоятельный V46 технический Chromium QA для шести компьютерных и шести мобильных сценариев, 4 сравнительных листа «эталон / текущий рендер», вкладка Studio V46, безопасная SHA256 сборка (BUILD/SKIP), раздельный отчёт технического покрытия и ручной художественной оценки. Проверки: 202/202 pytest (40 API + 162 site/tools); 12/12 Chromium offline, не HTTP browser E2E. Четыре пары макетов подготовлены, но пользователь не утверждал фактическое художественное совпадение.

Показатели: локальный сайт 100% по проверенному чек-листу, визуал ПК 90% и телефон 90% — наследуемые **ручные ориентиры V40**, не измеренное сходство; технический визуальный QA 100% на шести тестах каждого класса; движок 80% по 8/10 локальным критериям; коммерческий запуск 49,5% (около 50%) по старой весовой модели, PRODUCTION_BLOCKED.

Сверка всех 1100 V45 файлов: 965 оставлены без изменения, исходники 45 изменённых и 2 выведенных файлов сохранены под historical_v45/original_path_bytes. 88 файлов кеша/состояния, включая SQLite, не включены в выдачу по соображениям безопасности и чистоты пакета. Подробности в V46_SOURCE_PRESERVATION.json.
