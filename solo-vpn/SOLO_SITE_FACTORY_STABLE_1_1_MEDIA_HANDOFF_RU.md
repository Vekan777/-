# Solo Site Factory Stable 1.1 — материалы и шаблоны (24.10.2026)

Это памятка сохранности. **В этой GitHub-ветке нет полного кода Stable 1.1.** Полный проект доступен архивом `SOLO_SITE_FACTORY_STABLE_1_1_MEDIA_ENGINE.zip` в чате ChatGPT, SHA256 `a8e458470562d5cbb6ad77b1503c3ce8669e9b4a3f5f35aa6ee57db96b921f93`.

Изменения поверх отдельного движка Stable 1.0: `engine/assets.py` извлекает вырезки из макетов только с подтверждением прав, определяет кандидатов по контрастности, оптимизирует и улучшает растровые изображения, рисует оригинальные SVG и подключает на новые проекты, создаёт статические каталоги товаров из собственных JSON, ставит CSS-анимацию с поддержкой reduced-motion и бэкапами. `engine/online.py` ищет изображения Wikimedia Commons и собирает сведения об авторе/лицензии, предлагает MIT-шаблоны Start Bootstrap, сохраняет исходники GitHub по SHA без запуска JS, а также позволяет опционально генерировать/редактировать изображения через платный GPT Image API (ключ только из переменной окружения; явное одобрение цены, загрузки исходника и прав). В GUI новая прокручиваемая вкладка «Материалы и товары». Production gate блокирует неутверждённые файлы.

**Подтверждение:** чистая распаковка движка, запуск CLI и 46/46 локальных тестов, отдельный двухстраничный пример с 3 демонстрационными товарами, 4/4 автономных Chromium-сценариев (компьютер и телефон, главная и каталог), ZIP проверены на CRC. Интернет-поиск, загрузка шаблонов и платный AI проверены на фиктивных ответах/запретах; реальные внешние вызовы не подтверждены. Windows GUI физически не проверен.

Самостоятельные выдаваемые файлы в чате: `SOLO_SITE_FACTORY_STABLE_1_1_MEDIA_ENGINE.zip`, `SOLO_FACTORY_MEDIA_DEMO_WEBSITE.zip`, `SOLO_FACTORY_MEDIA_DEMO_DELIVERY.zip`, `SOLO_FACTORY_MEDIA_BROWSER_QA.zip`, `SOLO_FACTORY_MEDIA_RELEASE_SHA256.json`, подробная инструкция `MATERIALS_AUTOMATION_RU.md` внутри основного архива.

**Продукты разделены:** Solo Site Factory — независимый движок для разных проектов; Solo VPN остаётся отдельным сайтом, исходники VPN/Android находятся в предыдущих полных ZIP V46, не включаются в движок. Готовность самого движка по старому локальному чек-листу 90% (не проверено Windows GUI). Статический демосайт 100% по файловому QA, художественная приёмка отсутствует. Реальный Solo VPN, оплата и VPS/WireGuard по-прежнему не запущены/не подтверждены. Не обещать безошибочную автономную генерацию любого сайта или автоматически выдуманные реальные цены/товары.

**Дальнейшая работа:** исправлять конкретные defects с воспроизведением, не плодить бесконечные версии; проверять права на контент, UI Windows, легальные сетевые загрузки и e2e на размещённых проектах до production.
