# Solo Site Factory Stable 1.1 — усиление конвейера, 24.10.2026

Это **только документ передачи**, полный код находится в архиве `SOLO_SITE_FACTORY_STABLE_CONVEYOR_ENGINE.zip` текущего диалога. Не брать вместо него прежний код GitHub.

Продолжение 1.1 без новой серии версий: добавлен `factory.py finish --project <slug> [--with-browser] [--production]` и кнопка «ЗАВЕРШИТЬ САЙТ» в GUI. Конвейер: baseline QA → ремонт HTML (максимум 3 прохода, резервные копии) → повторный HTML+CSS QA → опциональный Chromium offline → readiness → отдельные webroot и delivery ZIP. В JSON `reports/LAST_CONVEYOR_RUN.json` записаны все шаги. При блокировке CLI возвращает код 2.

Исправлено: CSS url(...) и локальный @import проверяются на отсутствие файла/обход каталога. Каждый browser QA получает хеш всего site; изменение кода/ресурсов инвалидирует старый браузерный результат. Проверка скачиваемых GitHub ZIP-шаблонов отклоняет Windows backslash и ':' пути, ZIP casefold collisions, zip-slip и symlinks.

**Подтверждено:** 56/56 локальных pytest, повторные тесты и CLI pipeline после чистой распаковки архива двигателя, демонстрационный двухстраничный каталог (3 сгенерированных SVG, demo-товары, анимация, две независимые ZIP-поставки), 2/2 автономных Chromium-проверок на 390 и 1440px. Реальный Windows GUI и живые интернет-загрузки в данном цикле не проверены.

Отдельный сайт Solo VPN импортирован из `SOLO_VPN_SITE_PUBLIC_WEBROOT.zip`, 11 страниц прошли локальный статический QA, создан независимый preview delivery. Ни работа WireGuard/VPN, ни реальная оплата, ни Android release при этом не подтверждались.

Готовность демо: локальный сайт 100% по ограниченному QA, движок 90% (9/10 подтверждённых локальных пунктов), художественный визуал ПК/телефона не оценён. Коммерческая публикация заблокирована. Ранее полученные Solo VPN оценки (90/90 ручные, 49.5% коммерческие) не пересчитывались.

Файлы: `SOLO_SITE_FACTORY_STABLE_CONVEYOR_ENGINE.zip`; `SOLO_FACTORY_CONVEYOR_DEMO_WEBSITE.zip`; `SOLO_FACTORY_CONVEYOR_DEMO_DELIVERY.zip`; `SOLO_VPN_CONVEYOR_PREVIEW_DELIVERY.zip`; `SOLO_FACTORY_CONVEYOR_EVIDENCE.zip`; SHA256 и QA JSON.
