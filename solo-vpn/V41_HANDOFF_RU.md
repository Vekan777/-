## Сделано V41
- В V40 обнаружен реальный горизонтальный overflow 25px на странице privacy.html при ширине 320px; исправлен отдельным слоем `engine/static/assets/v41.css`.
- `tools/v41/fast_build.py`: ускоренная повторная генерация на SHA256 с пропуском неизменённых исходников и файлов результата, безопасным rebuild/rollback при изменениях.
- Размеры новых картинок без width/height восстанавливаются при сборке; для картинок V40 размеры уже были прописаны и не изменялись.
- В основной студии появилась кнопка быстрого V41-аудита, семь шкал и отчёт владельца вне публичной папки `site/`.
- Реальный локальный HTTP smoke: 80/80 файлов; автоматизированные тесты 155/155; 18/18 проверок экранов (320, 390, 1440px), без overflow/ошибок JavaScript и битых изображений.
- Браузер в окружении не мог открыть localhost (ERR_BLOCKED_BY_ADMINISTRATOR), поэтому 18 снимков получены Chromium из автономно внедрённого HTML и ресурсов (`offline_in_memory`), **не** из браузерного HTTP. Режим явно зафиксирован в `BROWSER_QA_V41.json`.
