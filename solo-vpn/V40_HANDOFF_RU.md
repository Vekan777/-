# Solo VPN V40 — передача проекта для следующего чата (24 октября 2026)

**ВАЖНО:** эта памятка не содержит всего кода V40: исходники находятся в архиве `SOLO_VPN_V40_FULL_PROJECT.zip`, созданном в разговоре ChatGPT. Ветка `solo-vpn-v8-build` содержит более ранние наработки, не подменяйте ими V40.

## Неизменяемые требования
- Название **Solo VPN**; владелец бесплатно пользуется собственным сервисом, пользователи получают пробный доступ **7 дней**, затем оплачивают 30/90/365 дней (платежи без скрытого автоматического включения).
- Внешний вид: чёрно-фиолетовый аниме-дизайн, теневой охотник и четыре утверждённых пользователем макета (главная, тарифы/скачивание, мобильная, FAQ). Оригиналы включены в папку `references/approved_user_mockups/` полного V40.
- Сохранять реальные HTML/CSS, 11 страниц, адаптивные WebP, Jinja2-движок, Tkinter Studio, API/WireGuard/Android исходники, Windows bat, инструкции и тесты. Никаких вымышленных VPN-серверов, клиентов, скоростей или доступных покупок.
- Не начинать разработку заново, продолжать версионно поверх V40. При каждой версии создавать ZIP, настоящие браузерные снимки, QA-отчёт и шкалы готовности.

## Нововведения V40
- В движок/Studio добавлена вкладка «Обзор готовности».
- `engine/config/readiness.json`: веса 15% визуал, 15% локальный сайт, 20% API, 15% Android, 15% домен/VPS, 10% оплата, 10% правовые данные и поддержка.
- `tools/check_v40_site.py`, `tools/readiness_v40.py`, `tools/test_v40_readiness.py`, Windows кнопка `ОБЗОР_ГОТОВНОСТИ_V40.bat`.
- Приватный обзор `OWNER_READINESS_V40.html` и JSON создаются **вне папки site/**, не публикуются.
- V40: 103 теста сайта + 40 API = 143 пройдено; 18 браузерных снимков 6 страниц на 320/390/1440; локальный аудит 10/10.
- Оценки: локальный сайт 100% по локальному чек-листу; визуал 90% **ручная оценка**; API 60% по компонентам; Android 60%; домен/VPS/платежи/юридическая приёмка 0% из-за отсутствия живых подтверждений; коммерческая готовность **50% по новой строгой шкале**. Старые 77% были приблизительной оценкой и не сопоставимы напрямую.

## Запуск и продолжение
Распаковать полный ZIP V40. `START_SITE_WINDOWS.bat` — локальный сайт; `OPEN_TEMPLATE_STUDIO_WINDOWS.bat` — студия; `ОБЗОР_ГОТОВНОСТИ_V40.bat` — пересчёт отчёта. Для тестов раздельно: `python -m pytest -q api/tests` и `python -m pytest -q tools/test_*.py`. Следующая версия V41 должна исходить **из полного V40 ZIP**. При необходимости попросить пользователя приложить этот архив и файл `HANDOFF_TO_NEXT_CHAT_V40_RU.md`; информация GitHub недостаточна для реконструкции всего V40.

**Нельзя объявлять 100% коммерческой готовности** до реального HTTPS/VPS/WireGuard, подтверждённой работы семидневного доступа и истечения срока, настоящих оплат, подписанного release APK и проверки прав на изображения.
